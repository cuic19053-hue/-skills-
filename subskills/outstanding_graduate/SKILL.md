# 优秀毕业生申请书 Skill

本 skill 处理"优秀毕业生申请书"全流程：材料类型分流 → 信息采集 → 4 年成长叙事撰写 → docx 生成 → 质检。优秀毕业生是本科生（研究生有专项文件）毕业前最高规格综合荣誉，评审跨度为大学 4 年（与"优秀学生"一学年跨度不同），要求总结 4 年综合表现与毕业去向。

支持三种材料形态、两种规格（省级/校级）、两等级（优秀/优良），并区分研究生分支与基层就业专项路径。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐、4 年 GPA 表与科研竞赛成果表自动嵌入）。

---

## §0 材料类型分流（必读）

不同省份/学校下发的"优秀毕业生申报材料"形态不同，**触发后第一件事是确认材料类型**，不能直接套用书信体模板。

### 0.1 三种材料形态对照

| 形态 | 适用地区/学校 | 字数 | 结构特征 | 典型场景 |
|------|--------------|------|----------|----------|
| 书信体申请书 | 多数省份/学校 | 1500~2500 字 | 标题+称呼+正文 5 段+结尾+落款 | 综合性大学常规申报 |
| 表格式登记表 | 浙江、北京等省 | "申请理由"栏 300~500 字 | 表格栏目填写（含"申请理由"/"获奖情况"/"学院意见"） | 省级统一登记表 |
| "主要事迹"附件 | 多省要求附 | 800~1500 字 | 4 段叙事文（思想/学业/科研实践/综合），与申请书互补 | 省级申报材料附件 |

### 0.2 触发后的分流决策树

1. 询问用户：**学校/省份下发的申报材料是什么格式？**（书信体 / 登记表 / 主要事迹附件 / 全部都要）
2. 若用户答"表格"或"登记表" → 走 §8 表格式申请书填写规范
3. 若用户答"书信"或"申请书" → 走 §7 书信体申请书撰写规范
4. 若用户答"主要事迹" → 走 §9 主要事迹附件写作方法
5. 若省级申报要求"申请书+主要事迹+登记表"三件套 → 三种均按规范分别生成
6. 若用户不确定 → 默认按书信体申请书生成，并提示"如学校下发登记表或要求主要事迹附件，可告知后补充"

### 0.3 形态选择的省际提示

- **浙江/北京**：常用《优秀毕业生登记表》表格形式，申请书正文压到 400 字以内
- **四川/江苏/湖北**：常用书信体申请书 2000~2500 字
- **黑龙江**：先校级评审 → 校级推荐后省级评审，省级申报须附校级优秀毕业生证书复印件
- **多省省级申报**：要求"申请书 + 主要事迹附件 + 登记表"三件套，三种均须准备

## §1 适用场景与触发条件

### 1.1 适用范围

用户提到"优秀毕业生""省优毕业生""校优毕业生""省级优秀毕业生""校级优秀毕业生""毕业生评优""优秀毕业生登记表""主要事迹""优良毕业生"等关键词，且本人应届毕业（大四下学期 / 研三下学期）。

### 1.2 不适用（需走其他 skill）

- 优秀学生 / 优秀团员 / 文明大学生（一学年跨度，1500~2000 字）→ 走评优其他 skill
- 国家奖学金（一学年跨度，1200~2000 字，侧重本学年表现）→ 走 national_scholarship
- 国家励志奖学金（前 30%、家庭经济困难）→ 走 scholarship_inspirational
- 保研推免申请书（侧重研究生申请，含推荐信）→ 走 graduate_recommendation

### 1.3 省校规格区分

- **省级**：规格高，配额 3%~5%（省际差异见 §3），原则上从校级优秀毕业生中产生
- **校级**：常规规格，配额 5%~10%，学院初审 + 学校终审
- 同一学生同年度可同时申报省校两级，但申请书须分别按规格调整数据展示，省级须附校级优秀毕业生证书复印件

### 1.4 研究生分支提示（重要）

研究生（硕士/博士）优秀毕业生评审条件与本科生差异显著，**本 skill 默认面向本科生**：

- 评审条件差异：需 2 次校级及以上奖学金（本科生 1 次即可）、科研成绩要求更高（须有论文/专利产出）、3 年叙事而非 4 年
- 学业表差异：硕士分学年 GPA 表改为 3 行（研一/研二/研三），博士按培养阶段叙事
- 毕业去向差异：研究生去向多为高校教职/科研院所/博后，去向呼应模板相应调整
- **建议研究生申报时提示用户**："研究生优秀毕业生评审条件与本科生不同，本 skill 默认面向本科生，建议查阅学校《研究生优秀毕业生评选办法》专项文件后申报。"

字段 `grad_student: true/false` 由 build.py 读取，true 时输出研究生分支提示信息。

### 1.5 基层就业专项（独立评选路径）

上海交大等校设有"基层就业专项"独立评选，要求：

- 已签订三方协议赴国家艰苦行业/中西部/东北/基层就业
- 申报材料须附已鉴证三方协议复印件
- 毕业去向段须明确写："已与 XX 单位签订三方协议（鉴证号 XXXXX），赴 XX（艰苦行业/中西部/东北/基层）就业"
- 评选周期与常规优秀毕业生同步，但单独配额、单独评审

字段 `grassroots_employment: true/false` 由 build.py 读取，true 时毕业去向段强制包含三方协议信息，且生成"基层就业专项"标识。

### 1.6 优秀 vs 优良区分

清华大学等校区分两等级：

- **优秀毕业生**（最高）：评审线高于优良，配额少
- **优良毕业生**（次高）：评审线低于优秀，配额多
- 申报时须确认学校是否有两等级，**若有两等级，先确认申报哪一级**，避免申报错误等级后无法改报

字段 `excellent_vs_good: true/false` 由 build.py 读取，true 时触发"先确认申报等级"的提问；申请等级标识 `apply_rank` 取值 `excellent`/`good`。

### 1.7 触发后第一步

1. 确认材料类型（书信体 / 登记表 / 主要事迹附件）→ §0
2. 核对绝对硬门槛 5 项 → §2
3. 区分规格（省级 / 校级 / 优秀 / 优良）→ §1.3 + §1.6
4. 询问学校下发模板的字数与称呼偏好 → §4 + §5
5. 区分本科生 / 研究生 → §1.4
6. 确认是否走基层就业专项 → §1.5

## §2 硬门槛

### 2.1 绝对硬门槛（5 项，不达标直接劝退）

下列 5 项为评审官方文件普遍明列的"绝对硬门槛"，任一不达标**直接劝退**，不要浪费用户时间继续撰写：

1. **无挂科、无违纪处分**（含考试作弊、学术不端、宿舍违纪等，4 年内任一学期均不可有）
2. **按时修完教学计划全部课程**（无欠学分、无延期毕业）
3. **体能测试达标**（参照《国家学生体质健康标准》，每年须达标，部分学校要求每年良好以上——四川某校评审细则明列此条）
4. **毕业证学位证可取得**（已通过毕业论文/设计开题，且进入中期以上阶段，无延毕风险）
5. **至少 1 项校级荣誉**（国家励志奖学金、校级三好学生、校级优秀学生干部、校级优秀团员、校级一二等奖学金均算；校级三等奖学金单独不算，须配其他校级荣誉）

### 2.2 竞争性门槛（建议值，未达标不一定劝退）

绝对硬门槛达标后，竞争性门槛决定竞争力：

| 规格 | 绩点建议 | 专业排名建议 |
|------|----------|--------------|
| 校级优秀毕业生 | GPA ≥3.0/4.0 | 专业前 40% |
| 省级优秀毕业生 | GPA ≥3.5/4.0 | 专业前 15% |
| 校级优良毕业生 | GPA ≥2.8/4.0 | 专业前 50% |

> **说明**：竞争性门槛为参考值，实际评审看同届竞争情况。如某年同届普遍 GPA 偏低，校级前 50% 也有机会；反之同届竞争激烈，前 15% 未必能上省级。

### 2.3 旧版过严门槛对比（已修正）

| 项 | 旧版门槛 | 新版门槛 | 修正理由 |
|----|----------|----------|----------|
| GPA | ≥85 或 3.5+/4.0 | 校级 ≥3.0 / 省级 ≥3.5 | 旧版过严，多数学校校级门槛低于 3.5 |
| 专业排名 | 前 10% | 校级前 40% / 省级前 15% | 旧版过严，校级实际前 30%~40% 即可 |
| 校级荣誉 | 至少 2 项 | 至少 1 项 | 旧版过严，1 项校级三好/优干/优团/奖学金即满足 |
| 体能测试 | 未列 | 必须达标（参照《国家学生体质健康标准》） | 四川某校评审细则明列，旧版遗漏 |

### 2.4 门槛未达标的处理话术

- 绝对硬门槛未达（如挂科/处分/欠学分）："优秀毕业生评审要求无挂科无处分/按时毕业/体能达标，建议确认是否满足全部 5 项硬门槛后再申报。本 skill 不建议代为撰写不达标的申请书。"
- 竞争性门槛未达但绝对门槛达："绝对硬门槛已达标，但竞争性指标（GPA/排名）略低于建议值。可申报校级优秀毕业生，省级建议谨慎。申请书撰写时须重点突出科研/实践/毕业去向的标志性成果以弥补。"

## §3 配额省际差异 + 省→校递进机制

### 3.1 配额省际差异表

| 省份 | 本科生 | 研究生 | 专科 | 备注 |
|------|--------|--------|------|------|
| 浙江 | 4% | 5% | 3% | 采用登记表形式 |
| 北京 | ≤5% | ≤5% | — | 部分高校单独评审 |
| 上海 | ≤5% | ≤5% | — | 设基层就业专项 |
| 江苏 | 3%~5% | 3%~5% | 2%~3% | 省级评审从严 |
| 四川 | 3%~5% | ≤5% | — | 体能测试硬门槛 |
| 黑龙江 | 校级推荐后省级评审 | — | — | 须附校级优秀毕业生证书复印件 |
| 湖北 | 3%~5% | ≤5% | — | 三件套申报 |
| 多省校级 | 5%~10% | ≤10% | — | 学院初审 + 学校终审 |

> 数据来源：各省教育厅/人社厅优秀毕业生评选通知（2024~2025 版），配额比例随年份微调，使用时建议核对当年通知。

### 3.2 省→校递进评审机制

**核心规则**：省级优秀毕业生原则上从校级优秀毕业生中产生（电子科技大学、西南交通大学等校文件明示）。

#### 3.2.1 递进流程

```
校级优秀毕业生申报 → 学院初审 → 学校终审 → 校级公示 → 获校级优秀毕业生
                                                    ↓
                              学校择优推荐 → 省级申报材料（须附校级证书复印件）
                                                    ↓
                                       省教育厅评审 → 省级公示 → 获省级优秀毕业生
```

#### 3.2.2 给用户的建议

- **未获校级优秀毕业生资格者**：不建议直接申报省级，应先申报校级
- **已获校级优秀毕业生者**：可凭校级证书申报省级，省级申报材料须附校级优秀毕业生证书复印件
- **同年度同申报**：可同时申报省校两级，但校级评审结果先出，省级评审依据校级结果择优推荐

#### 3.2.3 省级申报材料特殊要求

- 申请书须明确写"已获 XX 年校级优秀毕业生，特申报省级"
- 须附校级优秀毕业生证书复印件
- 须附学校推荐意见（学院 + 学校两级签字盖章）
- 须附 4 年完整成绩单（教务处盖章）
- 须附获奖证书复印件装订成册
- 须附毕业去向证明（保研拟录取通知/就业协议/西部计划录取通知）

## §4 字数三档化

### 4.1 三档字数对应

| 档位 | 字数 | 适用场景 | 形态 |
|------|------|----------|------|
| 登记表式 | 300~500 字 | 浙江/北京等用《优秀毕业生登记表》，"申请理由"栏 | 表格式 |
| 校级申请书 | 1500~2000 字 | 校级优秀毕业生申请书 | 书信体 |
| 省级申请书 | 2000~2500 字（上限不超过 3000 字） | 省级优秀毕业生申请书 | 书信体 |

### 4.2 字数选择规则

1. 询问用户："学校下发的模板要求字数是多少？"
2. 用户答"400 字"/"申请理由栏" → 走登记表式 300~500 字（§8）
3. 用户答"1500 字"/"2000 字" → 走校级 1500~2000 字
4. 用户答"2000 字"/"2500 字"/"3000 字" → 走省级 2000~2500 字（不超过 3000）
5. 用户不确定 → 按规格默认：校级 1500~2000 字，省级 2000~2500 字

### 4.3 字数配比（省级 2000~2500 字示例）

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 标题 + 称呼 | 不计 | — |

| 学业成绩 | 450~600 | 24% |
| 科研创新 | 400~550 | 22% |
| 社会实践 | 300~450 | 17% |
| 综合素质 | 200~300 | 10% |
| 结尾 | 80~150 | 5% |
| 落款 | 不计 | — |

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 开头 | 120~180 | 9% |

## §5 称呼 5 种选择

### 5.1 5 种称呼及使用频率

| 序号 | 称呼 | 使用频率 | 适用场景 |
|------|------|----------|----------|
| 1 | 尊敬的领导： | 45% | 最通用，多数综合性大学 |
| 2 | 敬爱的领导： | 25% | 多见于省优申报材料 |
| 3 | 尊敬的学校领导： | 15% | 校级偏多 |
| 4 | 尊敬的老师： | 10% | 部分高校（如师范类） |
| 5 | 尊敬的评审委员会： | 5% | 理工类院校 |

### 5.2 触发后主动询问

## §7 书信体申请书撰写规范

书信体申请书整体结构：

```
标题：省级/校级优秀毕业生申请书（黑体二号居中）

称呼：尊敬的领导：（顶格，全角冒号）—— 5 种可选，见 §5

开头（150~200 字）：
  身份 + 申报规格 + 4 年综合数据 3 项 + 毕业去向 + 进入正文

二、学业成绩（350~600 字，重点）
  4 年加权 GPA + 专业排名 + 分学年 GPA 表 + 英语计算机等级 + 奖学金汇总

三、科研创新（300~550 字）
  大创/科研立项 + 论文 + 专利 + 学科竞赛表

四、社会实践（250~450 字）
  学生工作 + 三下乡/志愿服务 + 实习经历

五、综合素质（150~300 字）
  文体特长 + 班级评价 + 兴趣爱好 + 体能测试达标

结尾（80~150 字）：
  4 年成长总结 + 毕业去向呼应 + 朴素表态 + "此致/敬礼！"

落款（右对齐）：
  申请人：XXX
  XXXX 年 XX 月 XX 日
```

### 7.1 标题

格式：黑体二号，居中，段前段后 12pt。

文本：根据规格动态填充——省级填"省级优秀毕业生申请书"（9 字），校级填"校级优秀毕业生申请书"（9 字），不要写"2025 届省级优秀毕业生申请书"。两等级学校如申报优良则填"校级优良毕业生申请书"。

### 7.2 称呼

详见 §5。5 种称呼均可，默认"尊敬的领导："，触发后主动询问偏好。

### 7.3 开头段落（150~200 字）

字数：150~200 字，1 段。

句式 3 句结构：
1. 身份 + 申报规格："我是 XX 学院 XX 专业 2021 级学生 XXX，特申报 2025 届省级/校级优秀毕业生。"
2. 4 年综合数据 3 项："大学 4 年加权 GPA 3.85/4.0，专业排名第 1/87；主持国家级大创 1 项，以第一作者发表 SCI 论文 1 篇；保研至清华大学计算机系。"
3. 进入正文："现将大学四年情况汇报如下："

禁止：抒情开头（时光荏苒/岁月如梭/四年光阴转瞬即逝/感慨万千）、感谢母校培养、回顾大学时光、套用"白驹过隙"等成语。

### 7.4 一、思想品德（220~350 字）

撰写要点（按 §13.2 与 §13.3 模板补充政治理论学习具体写法）：

1. **政治面貌与入党轨迹**（如适用）：按 7 节点清单完整填写：
   - 递交入党申请书（年月）
   - 列为入党积极分子（年月）
   - 党校培训班结业（年月+学时数）
   - 转为中共预备党员（年月）
   - 转为中共正式党员（年月）
   - 参加主题党日活动 X 次
   - 撰写理论学习心得 X 篇

2. **政治理论学习**：明确写出"认真学习习近平新时代中国特色社会主义思想，深入学习党的二十大和二十届三中全会精神"——见 §13.3 模板。

3. **学生干部履职**：至少 1 段，含职务、任期、组织活动数、服务人次、推动的具体成果。

4. **荣誉列表**：三好学生、优秀团员、优秀学生干部等（与科研类荣誉区分，科研类放在第三段）。

正面示例（约 150 字，含 7 节点）：
> 大一递交入党申请书，2023.03 列为入党积极分子，2023.06 完成党校培训班学习（32 学时）并结业，2024.06 转为中共预备党员，2025.06 转为中共正式党员。认真学习习近平新时代中国特色社会主义思想，深入学习党的二十大和二十届三中全会精神，参加主题党日活动 12 次，撰写理论学习心得 8 篇。担任班级团支书 4 学期，组织主题团日活动 12 场，覆盖同学 600 余人次，所在团支部获评 2024 年度校级五四红旗团支部。

反面示例：
> 我思想进步，积极向党组织靠拢。担任学生干部期间工作认真负责，深受师生好评。（无具体时间节点、无履职数据、无政治理论学习具体写法）

### 7.5 二、学业成绩（350~600 字，重点）

撰写要点：
1. 4 年加权 GPA 与专业排名：大学 4 年加权 GPA X.XX/4.0，加权平均分 XX.X，专业排名 X/N（前 X.X%）。
2. 分学年 GPA 表（必填表格）：学年/GPA/加权平均分/排名 4 列，体现 4 年成长轨迹。
3. 主干课程亮点：列举 3~5 门 90+ 课程。
4. 英语计算机等级：CET-4、CET-6、计算机等级。
5. 奖学金汇总：4 年获国家奖学金 X 次、校级一等奖学金 X 次等。
6. 毕业论文/设计：题目 + 进展 + 导师（一句话即可）。

分学年 GPA 表示例：
| 学年 | GPA | 加权平均分 | 专业排名 |
|------|-----|-----------|----------|
| 大一 | 3.60 | 85.2 | 5/87 |
| 大二 | 3.80 | 88.5 | 3/87 |
| 大三 | 3.90 | 91.0 | 1/87 |
| 大四 | 3.95 | 92.5 | 1/87 |

### 7.6 三、科研创新（300~550 字）

撰写要点：
1. 大创/科研立项：项目名称、级别、角色、起止时间、产出（含可量化数据）。
2. 论文：题目、期刊名、级别（SCI/EI/中文核心）、作者排序、录用或见刊时间、IF（如有）。多篇用列表。
3. 专利：名称、类型、申请号、状态、本人排序。
4. 学科竞赛：竞赛全称、奖项、时间、角色。多个用表格。

科研创新成果表示例：
| 类别 | 名称 | 级别 | 角色 | 时间 |
|------|------|------|------|------|
| 大创 | 分布式光伏故障智能诊断系统 | 国家级 | 主持 | 2024.03-2025.03 |
| 论文 | 基于对比学习的法律问答系统 | SCI | 第一作者 | 2025.03 见刊 |
| 竞赛 | 全国大学生数学建模竞赛 | 国家二等奖 | 队长 | 2025.05 |

禁止：
- "首次""先进""填补空白"等无支撑词
- 论文不写期刊级别
- 竞赛不写奖项级别
- 大创不写角色（主持 vs 参与）

### 7.7 四、社会实践（250~450 字）

撰写要点：
1. 学生工作：学生干部职务、任期、履职数据。
2. 三下乡/志愿服务：参与次数、地点、角色、服务时长、服务对象、产出（如调研报告被采纳）。
3. 实习经历：单位、岗位、时长、产出（用 1~2 句话）。

正面示例（约 120 字）：
> 大学 4 年累计志愿服务时长 320 小时。参与三下乡 2 次：2023.07 赴云南怒江开展教育扶贫支教 14 天，授课 32 课时；2024.07 赴甘肃定西开展电商助农调研，撰写调研报告 1 份（约 1.5 万字），被当地农业局采纳。2024.07-2024.09 在字节跳动实习，参与推荐系统优化项目，提升 CTR 3.2%。

### 7.8 五、综合素质（150~300 字）

撰写要点：
1. 文体特长：乐器、体育、书法、演讲等，含等级证书与比赛/演出经历。
2. 班级评价：同学关系、宿舍文明、班级集体荣誉。
3. 兴趣爱好：与综合素质相关的，不堆砌。
4. 体能测试达标：参照《国家学生体质健康标准》，每年须达标（部分学校要求良好以上）。

禁止：纯抒情（"我兴趣广泛，热爱生活"），用具体经历代替。

### 7.9 结尾（80~150 字）

句式 3 句结构（按 §13.8 双段式模板）：
1. 4 年成长总结："以上是我大学四年的成长汇报。"
2. 毕业去向呼应："即将前往清华大学攻读研究生 / 入职字节跳动 / 赴新疆开展基层服务，我将带着母校的教诲继续努力。"
3. 朴素表态："无论评选结果如何，我都将以优秀毕业生的标准严格要求自己。"

加固定格式：
> 此致
> 敬礼！

禁止：
- "恳请领导批准"
- "完全符合评选条件"
- "深感母校培养之恩"等抒情

### 7.10 落款

格式：右对齐，宋体小四。

文本：
> 申请人：XXX
> XXXX 年 XX 月 XX 日

日期用阿拉伯数字（与全文统一），不要中文大写。

### 7.12 4 年成长叙事方法

优秀毕业生与"优秀学生"最大差异：要求呈现 4 年成长叙事，不是按时间流水账。

#### 7.12.1 三种叙事结构

**按时间线叙事**（适合 GPA 持续上升、有明确成长轨迹者）：
- 大一：基础扎实，GPA 3.6
- 大二：进入实验室，开始科研
- 大三：主持大创，发表论文
- 大四：保研清华，继续深耕

**按维度叙事**（适合多维度均有突出表现者）：
- 学业：4 年 GPA 3.85
- 科研：主持大创 + SCI 论文
- 实践：三下乡 + 实习
- 素质：文体特长

**按里程碑叙事**（适合有标志性事件者）：
- 大二参加数学建模获国二
- 大三发表 SCI 一作
- 大四保研清华

#### 7.12.2 时间线叙事示例（约 150 字）

> 回顾大学四年，我的成长呈现明显的台阶式上升。大一专注于打牢数理基础，GPA 3.60；大二进入张教授实验室接触自然语言处理，主持校级大创 1 项；大三主持国家级大创，以第一作者在《XX》发表 SCI 论文 1 篇，GPA 提升至 3.90；大四完成毕业设计并保研至清华大学计算机系人工智能方向，GPA 3.95。四年加权 GPA 3.85，专业排名第 1/87。

#### 7.12.3 维度叙事示例（约 120 字）

> 大学四年，我在学业、科研、实践、素质四维度同步推进。学业方面，4 年加权 GPA 3.85/4.0，专业排名第 1/87；科研方面，主持国家级大创 1 项，发表 SCI 论文 1 篇（第一作者）；实践方面，累计志愿服务 320 小时，参与三下乡 2 次；素质方面，钢琴十级，担任校合唱团团长 2 学期。

#### 7.12.4 里程碑叙事示例（约 100 字）

> 大学四年有三个里程碑。大二参加全国大学生数学建模竞赛获国家二等奖，确立了"用算法解决实际问题"的研究方向；大三主持国家级大创《分布式光伏故障智能诊断系统》，以第一作者发表 SCI 论文 1 篇，找到对比学习的研究兴趣；大四保研至清华大学计算机系，将在人工智能方向继续深耕。

#### 7.12.5 选择建议

- GPA 持续上升（如 3.6→3.95）→ 时间线叙事
- 多维度均衡发展 → 维度叙事
- 有 2~3 个标志性事件 → 里程碑叙事
- 不确定 → 维度叙事最稳妥

#### 7.12.6 反面：流水账叙事

❌ 反面示例：
> 大一我参加了新生入学教育。大一下学期我加入了学生会。大二我参加了数学建模竞赛。大二下学期我开始进实验室。大三我主持了大创。大四我保研了。

问题：每个事件孤立、无主线、无成长逻辑、无数据。

#### 7.12.7 三种叙事结构对比

| 维度 | 时间线叙事 | 维度叙事 | 里程碑叙事 |
|------|-----------|----------|-----------|
| 适用对象 | GPA 持续上升者 | 多维度均衡发展者 | 有 2~3 个标志性事件者 |
| 主线 | 时间（大一→大四） | 维度（学业/科研/实践/素质） | 事件（国二/SCI/保研） |
| 字数 | 150~200 字 | 120~150 字 | 100~150 字 |
| 优点 | 体现成长轨迹 | 突出多维度均衡 | 聚焦高光时刻 |
| 缺点 | 易变流水账 | 缺乏时间感 | 可能遗漏中等表现 |
| 适用 GPA | 3.6→3.95 上升型 | 3.85+ 稳定型 | 3.7+ 突破型 |

#### 7.12.8 4 年成长叙事常见误区

**误区 1：把"成长"等同于"成绩上升"**。成长不仅是 GPA，还包括科研角色升级（参与→主持）、实践深度提升（参与→组织）、思想成熟（团员→党员）。

**误区 2：4 年叙事变成 4 段独立陈述**。每段必须有内在逻辑（如"大二进实验室 → 大三主持大创 → 大四保研"是因果链，不是并列）。

**误区 3：忽略"未达成"的部分**。如大二某次竞赛未获奖但学到经验，可作为成长节点，比纯罗列成功更有说服力。

**误区 4：4 年叙事与毕业去向脱节**。叙事应自然导向毕业去向（如叙事提到大三找到对比学习兴趣，结尾呼应保研清华人工智能方向）。

#### 7.12.9 毕业去向与本科经历呼应模板

**升学呼应**："本科阶段在 XX 方向的科研积累（含 XX 大创/XX 论文）与保研至 XX 学校 XX 方向高度契合，将在 XX 教授指导下继续深入研究。"

**就业呼应**："本科 XX 段实习经历（在 XX 公司参与 XX 项目）使我确认对 XX 行业的兴趣，即将入职 XX 公司担任 XX 岗位，与本科专业高度匹配。"

**创业呼应**："本科阶段主持的 XX 大创项目已孵化为创业项目，与团队联合创立 XX 公司，主攻 XX 领域，已获 XX 轮融资。"

**西部计划呼应**："本科 4 年累计志愿服务 XX 小时，赴 XX 地三下乡的经历坚定了我投身基层的决心，已入选西部计划赴 XX 地开展服务。"

**留学呼应**："本科阶段在 XX 方向的科研兴趣驱动我申请 XX 学校硕士项目，计划毕业后回国攻读博士，将所学应用于国内 XX 产业。"

**基层就业专项呼应**："已与 XX 单位签订三方协议（鉴证号 XXXXX），赴 XX（中西部/艰苦行业/基层）就业，将本科所学应用于国家战略需求地区。"

## §9 主要事迹附件写作方法（新增章节）

多省申报材料要求附 800~1500 字"主要事迹"附件，与申请书正文互补，**更偏叙事**（申请书更偏数据）。

### 9.1 与申请书的差异

| 项 | 申请书 | 主要事迹附件 |
|----|--------|--------------|
| 字数 | 1500~2500 字 | 800~1500 字 |
| 风格 | 数据+表格为主 | 叙事+成长故事为主 |
| 结构 | 5 段（思想/学业/科研/实践/素质） | 4 段（思想/学业/科研实践/综合） |
| 表格 | 必用（GPA 表+成果表） | 不用表格，纯文字 |
| 第一人称 | "我"为主 | "我"为主，可适度用"该生"（学校推荐时） |

### 9.2 4 段模板

**第 1 段：思想成长（200 字）**
> 该生政治立场坚定，2022.09 递交入党申请书，2023.03 列为入党积极分子，2023.06 完成党校培训班学习（32 学时）并结业，2024.06 转为中共预备党员，2025.06 转为中共正式党员。认真学习习近平新时代中国特色社会主义思想，深入学习党的二十大和二十届三中全会精神，参加主题党日活动 12 次，撰写理论学习心得 8 篇。担任班级团支书 4 学期，所在团支部获评 2024 年度校级五四红旗团支部。

**第 2 段：学业成长（400 字）**
> 大学四年学业呈持续上升趋势。大一 GPA 3.60 专注数理基础；大二 GPA 3.80 进入 XX 教授实验室接触 XX 方向；大三 GPA 3.90 主持国家级大创、发表 SCI 一作；大四 GPA 3.95 完成毕业设计并保研至清华大学计算机系人工智能方向。四年加权 GPA 3.85/4.0，专业排名 1/87（前 1.1%）。CET-6 542 分，计算机二级 C 语言优秀、三级数据库技术。获国家奖学金 1 次、校级一等奖学金 3 次。主干课程数据结构 95 分、操作系统 93 分、机器学习 92 分。

**第 3 段：科研实践（300 字）**
> 主持国家级大创《分布式光伏故障智能诊断系统》（2024.03-2025.03），负责整体方案设计与对比学习模块实现，项目结题评估优秀；以第一作者在《XX》（SCI 二区，IF 5.2）发表论文《基于对比学习的法律问答系统》，2025.03 见刊；以第二作者在 EMNLP 2024（CCF-B 类会议）发表论文 1 篇。参加全国大学生数学建模竞赛获国家二等奖（队长，12000 队参赛）。累计志愿服务时长 320 小时，参与三下乡 2 次，撰写调研报告 1 份（约 1.5 万字）被当地农业局采纳。

**第 4 段：综合发展（200 字）**
> 担任学院学生会主席 1 学年（2024.09-2025.06），组织迎新晚会、运动会等大型活动 8 场，累计参与 2000+ 人次，推动学院学生会获评 2024 年度"校级优秀学生组织"。钢琴十级（中央音乐学院考级），担任校合唱团团长 2 学期，组织校内演出 6 场。宿舍连续 4 学期获评"文明宿舍"，班级获评 2024 年度校级先进班集体。每年体能测试均达标（参照《国家学生体质健康标准》）。

### 9.3 撰写注意事项

1. 主要事迹与申请书**内容互补不重复**：申请书强调数据，事迹强调故事
2. 字数严格控制 800~1500 字，4 段字数配比约 200:400:300:200
3. 不用表格，纯文字段落
4. 第一人称"我"为主，部分学校要求"该生"（学校推荐视角），按学校模板调整
5. 每段须有具体时间节点与可量化数据，不要纯抒情
6. 4 段须有内在成长逻辑（思想→学业→科研实践→综合），不是简单罗列

## §10 评审标准（5 维度框架）

### 10.1 5 维度框架（弱化合成权重）

**重要说明**：原 SKILL.md 列出的"学业 30%/科研 25%/实践 20%/素质 15%/思想 10%"权重表为合成数据，**官方评审文件未公开具体权重**，故本版改为只保留 5 维度框架，不附具体百分比。

5 维度框架：

| 维度 | 评审关注点 |
|------|------------|
| 学业成绩 | 4 年加权 GPA、专业排名、英语六级、奖学金次数与级别 |
| 科研创新 | 大创级别与角色、论文级别与作者排序、竞赛级别 |
| 社会实践 | 学生干部履职、三下乡、志愿服务时长、实习 |
| 综合素质 | 文体特长、班级评价、人际关系、体能测试达标 |
| 思想品德 | 入党情况、政治理论学习、思想觉悟、政治立场 |

**评审规则**：5 维度均需覆盖，无公开权重；评审委员会综合评议。

### 10.2 硬门槛达标后的竞争性评议

硬门槛达标后，竞争性评议侧重（**评审关注度参考值**，非官方权重）：

- 学业 + 科研：约 60%（最重）
- 实践：约 25%
- 素质 + 思想：约 15%

撰写时按此关注度分配字数与数据详略——学业+科研合计占全文 42%~46%（见 §4.3）。

### 10.3 省校规格与评审线对应

| 规格 | 评审特点 | 数据展示要求 |
|------|----------|--------------|
| 省级优秀毕业生 | 校级推荐后省级评审，竞争激烈 | 论文含 IF、竞赛含参赛规模、奖学金含次数与级别 |
| 校级优秀毕业生 | 学院初审+学校终审，相对宽松 | 论文含期刊级别、竞赛含奖项级别、奖学金含次数 |
| 校级优良毕业生 | 评审线低于优秀，配额多 | 数据展示可适度简化 |

### 10.4 省校通过率参考

> 省级优秀毕业生通过率约 30%（校级推荐后省级评审），校级约 60%。评审专家 5 人/项目，每份材料阅读 3~5 分钟（见 §11）。

### 10.5 评分不达标补救方向

- 学业偏弱：补充分学年 GPA 上升轨迹、CET-6 高分、主干课程亮点
- 科研偏弱：补充大创角色（主持 vs 参与）、论文作者排序、专利状态
- 实践偏弱：补充学生干部任期与履职数据、志愿服务时长
- 素质偏弱：补充文体特长等级证书、班级集体荣誉
- 思想偏弱：补充党校结业证书、主题党日组织经历、理论学习心得篇数

## §11 评审专家视角反推写作法（新增章节）

### 11.1 评审专家工作模式

- 评审专家 5 人/项目
- 每份材料阅读 **3~5 分钟**
- 重点关注 4 类信息（按阅读优先级）

### 11.2 4 类信息及阅读时长

| 序号 | 关注点 | 阅读时长 | 写作策略 |
|------|--------|----------|----------|
| 1 | 硬门槛是否达标 | 10 秒 | 开头段直接亮 GPA/排名/挂科情况/处分情况 |
| 2 | 有无标志性成果 | 30 秒 | 开头段或学业段突出国家级大创/SCI 一作/国家一等奖 |
| 3 | 4 年成长叙事是否有逻辑 | 60 秒 | 学业+科研段按时间线/里程碑叙事，每段有内在逻辑 |
| 4 | 毕业去向是否明确 | 10 秒 | 结尾段明确单位+岗位+地域+签约时间 |

### 11.3 反推写作顺序

撰写时按"硬门槛 → 标志成果 → 成长叙事 → 去向"顺序铺排，让专家 5 分钟内能定位加分点：

1. **开头段（前 100 字）**：硬门槛 + 标志成果
   - "大学 4 年加权 GPA 3.85/4.0，专业排名第 1/87"（硬门槛 10 秒可定位）
   - "主持国家级大创 1 项，以第一作者发表 SCI 论文 1 篇"（标志成果 30 秒可定位）

2. **学业+科研段（中段 800 字）**：成长叙事
   - 分学年 GPA 表 + 科研创新成果表（60 秒可扫完）
   - 每段有成长逻辑（大一基础→大二进实验室→大三主持大创→大四保研）

3. **结尾段（后 100 字）**：毕业去向
   - "即将前往清华大学攻读研究生"（去向 10 秒可定位）

### 11.4 5 分钟内可定位的加分点清单

撰写完成前，自查专家能否在 5 分钟内定位以下加分点：

- [ ] 4 年 GPA + 专业排名（开头 10 秒可定位）
- [ ] 标志性成果 1~2 项（开头 30 秒可定位）
- [ ] 分学年 GPA 表（学业段可定位）
- [ ] 科研创新成果表（科研段可定位）
- [ ] 学生干部任期与履职数据（实践段可定位）
- [ ] 志愿服务总时长（实践段可定位）
- [ ] 毕业去向（结尾段可定位）

任一项无法在 5 分钟内定位，重新调整段落顺序或加粗关键数据。

### 11.5 评审专家反感的具体表现

评审专家在 3~5 分钟阅读中，若发现以下情况会直接降分或淘汰：

1. **数据前后不一致**：开头说 GPA 3.85，正文表格显示 3.80 → 直接淘汰（评审怀疑造假）
2. **时间逻辑错乱**：大三转预备党员，大四才递交入党申请书 → 直接淘汰
3. **雷同率过高**：与网络范文雷同率超 30% → 取消资格
4. **关键数据缺失**：分学年 GPA 表只有 3 行（缺大四）→ 降分
5. **毕业去向模糊**：仅写"已保研"无学校全称 → 降分
6. **政治用语错误**：写"20 大精神"而非"党的二十大和二十届三中全会精神" → 降分
7. **形容词堆砌**：每段都以"我积极""我努力""我热心"开头 → 降分
8. **学生干部头衔无履职**：仅写"担任学生会主席"无任期无数据 → 降分

### 11.6 评审专家加分的具体表现

评审专家在 3~5 分钟阅读中，若发现以下情况会加分：

1. **开头 100 字内亮出 3 个标志性数据**：GPA/排名/标志性成果 → 加分
2. **分学年 GPA 表呈持续上升趋势**：3.6→3.8→3.9→3.95 → 加分
3. **科研段含 IF 与作者排序**：SCI 二区 IF 5.2，第一作者 → 加分
4. **实践段含被采纳证明**：调研报告被当地农业局采纳 → 加分
5. **毕业去向明确且呼应本科**：保研清华人工智能方向，呼应本科对比学习研究 → 加分
6. **入党轨迹 7 节点完整**：递交申请书→积极分子→党校结业→预备党员→正式党员 → 加分
7. **体能测试每年达标**：参照《国家学生体质健康标准》每年达标 → 加分
8. **学生干部含推动成果**：推动学院学生会获评"校级优秀学生组织" → 加分

## §14 docx 生成调用规范

### 14.1 调用命令

```bash
# 方式 1：使用 JSON 数据文件
python build.py --data data.json --out output.docx

# 方式 2：使用内置示例数据（演示用）
python build.py --demo --out /tmp/test_outstanding_graduate.docx

# 方式 3：查看帮助
python build.py --help
```

data.json 字段定义见 §6 信息采集清单，所有字段均可选填，缺字段会触发校验警告但不阻断生成。

### 14.2 生成流程

1. 解析 JSON → 2. 校验数据完整性（输出 warnings）→ 3. 按 material_type 路由生成（letter/form/appendix）→ 4. 构建 docx → 5. 保存到指定路径

### 14.3 三种 material_type 的生成路径

- `material_type: letter` → 走书信体生成路径（标题→称呼→开头→5 段正文→结尾→落款）
- `material_type: form` → 走登记表生成路径（表格栏位填写，"申请理由"栏按 §8.2 模板）
- `material_type: appendix` → 走主要事迹附件生成路径（4 段叙事文，无表格无称呼）

### 14.4 输出文件规范

A4 纸张，上下 2.54cm 左右 2.5cm 页边距，黑体二号标题居中，宋体小四正文 1.5 倍行距首行缩进 2 字符，分学年 GPA 表与科研创新成果表自动嵌入，"此致/敬礼！"格式，落款右对齐，页脚居中页码。

### 14.5 输出文件命名建议

- 省级书信体：`省级优秀毕业生申请书_张明_2025.docx`
- 校级书信体：`校级优秀毕业生申请书_张明_2025.docx`
- 登记表：`优秀毕业生登记表_张明_2025.docx`
- 主要事迹附件：`主要事迹_张明_2025.docx`
- 优良毕业生：`校级优良毕业生申请书_张明_2025.docx`

文件名包含规格、姓名、毕业年份，便于学院归档。

### 14.6 缺失字段处理

- P0 必采字段缺失：触发 warning，仍生成 docx，但对应段落用占位符 `___` 标注，提醒用户补全
- P1 重要字段缺失：触发 warning，对应段落省略或简化
- P2 可选字段缺失：不触发 warning，直接省略

### 14.7 build.py 须同步更新的字段（重要）

本版 SKILL.md 新增以下字段，**build.py 须同步更新**以正确读取：

| 字段名 | 类型 | 取值 | build.py 处理逻辑 |
|--------|------|------|-------------------|
| `material_type` | string | letter / form / appendix | 路由生成路径（见 §14.3） |

8. 标题生成函数按 `apply_rank` 区分"优秀/优良"

## §15 红线规则与免责声明

### 15.1 红线规则（不可违反）
