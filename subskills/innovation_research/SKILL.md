# 大创-创新训练项目申报书 Skill

本 skill 处理"大学生创新创业训练计划-创新训练项目"申报书全流程：信息采集 → 栏目撰写 → docx 生成 → 质检。仅处理"创新训练"子类（学术研究型），创业训练/创业实践请走创业类 skill。

教育部确立的"大创"三大原则：**兴趣驱动、自主实践、重在过程**。本 skill 全流程体现该原则（详见 §7）。

输出文件：可提交的 .docx（A4 纸张，宋体小四正文，黑体三号标题，1.5 倍行距，首行缩进 2 字符）。

## §1 适用场景与触发条件

**适用**：用户提到"大创""创新训练项目""大学生创新创业训练计划""国家级/省级/校级大创申报书""创新训练项目申报"等关键词，且项目产出为论文/研究报告/原型系统（非商业计划书）。

**不适用**（需走其他 skill）：
- 创业训练项目（产出商业计划书）→ 走创业训练 skill
- 创业实践项目（已注册公司运营）→ 走创业实践 skill
- 校级科研立项（非大创体系，经费 2000~5000 元）→ 走科研立项 skill
- 学科竞赛立项 → 走竞赛立项 skill

**触发后第一步**：确认项目类型为"创新训练"（非创业训练/创业实践）。若用户未明确，按创新训练处理并告知。

**触发后第二步**：确认项目级别（国家级/省级/校级），按 §2 7 维度对比表差异化处理。

## §2 国家级 vs 省级 vs 校级 7 维度对比表

### 2.1 七维度对比表

不同级别评审重点、团队规模、经费区间、预期成果差异显著，撰写前必须明确级别并按下表差异化处理。

| 维度 | 国家级 | 省级 | 校级 |
|------|--------|------|------|
| **创新要求** | 高（前沿突破，需有理论/方法新意） | 中（应用创新，解决实际问题） | 较低（训练性，掌握科研方法即可） |
| **研究深度** | 深，可结合导师在研国家级课题 | 适中，易落地，强调地方/行业需求 | 浅，训练科研方法与流程 |
| **团队要求** | 3~5 人（专业互补强） | 2~5 人 | 1~3 人 |
| **预期成果** | 核心期刊论文 1~2 篇 + 发明专利申请 1 项 + 实物原型 1 套 | 省级期刊论文 1 篇 + 实用新型/软著 1 项 + 产品原型 1 套 | 任一成果即可（研究报告/小论文/原型） |
| **立项率** | 10%~15%（竞争激烈） | 20%~30% | 30%~50% |
| **重点方向** | 前沿科技（AI/芯片/生物医药/新能源） | 应用/地方需求（区域经济/乡村振兴/产业升级） | 训练性课题（课程延伸/小型调研） |
| **经费区间** | 10000~20000 元 | 5000~10000 元 | 2000~3000 元 |

### 2.2 立项率概念澄清（避免误用）

⚠️ "立项率"在不同语境指代不同，必须澄清：

| 概念 | 定义 | 数据 |
|------|------|------|
| **立项率**（申报→立项） | 学校申报项目数 → 成功立项数（含校级立项）的比例 | 国家级 10%~15%；省级 20%~30% |
| **校级评审通过率**（校级→上级推荐） | 校级立项项目中 → 被推荐到省级/国家级的比例 | 约 30%~50% |

撰写申报书时，立项率数据仅用于背景说明（如"省级立项率约 25%，本项目需突出创新点以提升竞争力"），**不得编入申报书正文**。

### 2.3 级别差异化处理清单

明确级别后，撰写时按以下清单差异化：

- **国家级**：创新点 ≥3 个、经费 1~2 万、预期成果含"核心期刊论文 + 发明专利 + 实物原型"、立项背景突出前沿性与国家战略契合
- **省级**：创新点 ≥2 个、经费 5 千~1 万、预期成果含"省级期刊 + 实用新型/软著 + 产品原型"、立项背景突出地方需求与应用价值
- **校级**：创新点 ≥1 个、经费 2~3 千、预期成果任一即可、立项背景突出训练价值与课程延伸

### 3.3 内容素材（按栏目逐一采集）

**项目简介素材**：一句话讲清"做什么 + 为谁做 + 怎么做 + 产出什么"。让用户口述再整理。

**立项背景素材**：
- 价值导向开篇句（响应国家战略/家国情怀/正确价值观，见 §5）
- 时代背景关键词（政策/行业/学术趋势，2~3 句）
- 现实痛点（具体场景/人群/数据，必须可量化）
- 国内外研究现状（已有 3~5 个相关研究/产品 + 不足）
- 项目意义（理论/实践/社会，三选二即可）

**研究内容素材**：3~5 个子任务，每任务让用户讲"做什么 + 用什么方法 + 预期产出"。

**创新点素材**：先判断项目类型（算法/硬件/应用），按 §6 对应模板采集。每个创新点必须让用户提供"对比对象 + 区别 + 量化优势"。若用户说不清对比对象，追问"传统方法是什么？为什么你的更好？数据呢？"

**技术路线素材**：总体流程（5 个左右阶段）+ 每阶段方法 + 数据来源 + 软件/硬件工具。

**进度安排素材**：按月划分，每阶段标注交付物。留 1~2 月弹性。

**预期成果素材**：按级别差异化（见 §9）。论文 X 篇（注明拟投期刊级别）、专利 X 项、系统 X 套、报告 X 份。

**经费预算素材**：5 类科目（资料/差旅/材料/会议/其他），每项金额 + 计算依据。注意 §8.3 合规硬约束。

**前期基础素材**：团队相关课程/项目经验 + 指导教师科研项目 + 实验室设备条件。

### 3.4 字段优先级

| 优先级 | 字段 | 缺失影响 |
|--------|------|----------|
| P0 必填 | project_name/leader_name/leader_id/college/advisor_name/project_level | 申报书无法生成 |
| P0 必填 | project_type/project_source/discipline/duration/budget_total | 基本信息表不完整 |
| P0 必填 | abstract/background/research_content/innovations | 核心栏目空白 |

| P3 可选 | key_problems/midterm_check_plan | 看学校模板是否要求 |

### 3.5 追问话术

| 场景 | 话术 |
|------|------|
| 项目名称超 25 字 | "名称超 25 字评审会扣分，建议精简为 XXX（X 字），是否同意？" |

### 3.6 复述确认

全部采集完后，按申报书栏目顺序复述给用户：
"我已采集所有信息，按申报书顺序复述如下：① 项目名称：XXX ② 级别：国家级 ③ 负责人：XXX ④ ... 请确认无误或补充修正。"

复述格式严格按 12 栏目顺序：封面 6 字段 → 基本信息 9 行 → 项目简介 4 句 → 立项背景 4 段 → 研究内容 3 子节 → 创新点 → 技术路线 → 进度表 → 预期成果 → 经费预算 → 前期基础 → 签字栏（含指导频次声明 + 知识产权归属）。

用户确认后才进入撰写阶段。任何字段"待定""之后再说"——必须当场追问，不允许留空。

## §4 项目名称命名模板库

### 4.1 两套典型模板（按级别）

**模板 A（国家级偏前沿）**：`基于 XX 的 XX 系统设计与研发`

- 例 1：基于深度学习的智能垃圾分拣机器人设计与研发
- 例 2：基于多模态融合的光伏故障智能诊断系统设计与研发
- 例 3：基于强化学习的柔性机械臂轨迹规划算法研究与实现

**模板 B（省级偏应用）**：`XX 设计与实践——以 XX 为例`

- 例 1：校园二手书循环利用平台设计与实践——以 XX 大学为例
- 例 2：基于小程序的乡村物流配送系统设计与实践——以 XX 县为例
- 例 3：智慧养老社区服务模式设计与实践——以 XX 社区为例

### 4.2 禁用模板（评审扣分项）

| 禁用模板 | 问题 | 修改建议 |
|----------|------|----------|
| `人工智能应用研究` | 过大过空，无具体场景与方法 | 加"基于 XX 的 XX 应用研究" |
| `基于面向智能的 XX 研究` | 堆砌介词（基于+面向），冗余 | 删"面向"，留"基于 XX 的 XX 研究" |
| `XX 系统的研究与应用前景分析` | "应用前景分析"非大创产出 | 改"XX 系统设计与研发" |
| `XX 技术在 XX 领域的探索性研究` | "探索性"自降档次 | 删"探索性"，改"XX 技术在 XX 领域的应用研究" |
| `基于 XX 的 XX 系统的研究与实现与应用` | 三个"与"堆砌 | 精简为"基于 XX 的 XX 系统设计与研发" |

### 4.3 命名 4 要素自检

项目名称必须包含以下要素中至少 3 个：
1. **技术/方法**（如"基于深度学习""基于多模态融合"）
2. **对象/场景**（如"光伏故障""智能垃圾分拣"）
3. **产出形态**（如"系统""平台""算法""机器人"）
4. **动作**（如"设计与研发""设计与实践""研究与实现"）

≤25 字硬约束。超 25 字评审会扣分（规范性维度 10%）。

## §5 立项背景"价值导向"开篇句（北师大导向性要求）

### 5.1 价值导向开篇句模板

北师大通知明确："选题应弘扬正确价值观、体现家国情怀、符合国家发展战略"。立项背景第一段（时代背景）开头**必须**用价值导向开篇句。

**模板**：
> 本项目选题响应[国家战略/家国情怀/正确价值观]，[契合 XX 政策导向]。

**示例 1（新能源类）**：
> 本项目选题响应我国"双碳"战略导向，契合《"十四五"现代能源体系规划》要求。2024 年分布式光伏装机量突破 6 亿千瓦（国家能源局数据），年均增速 35% 以上。

**示例 2（乡村振兴类）**：
> 本项目选题响应"乡村振兴"战略导向，契合《数字乡村发展战略纲要》要求。2024 年农村网络覆盖率突破 98%（工信部数据），智慧农业年均增速 20% 以上。

**示例 3（医疗健康类）**：
> 本项目选题响应"健康中国 2030"战略导向，契合《"十四五"卫生健康人才发展规划》要求。2024 年基层医疗机构诊疗量突破 45 亿人次（卫健委数据），年均增速 8% 以上。

### 5.2 价值导向关键词库

| 战略类 | 政策类 | 价值观类 |

### 6.5 创新点通用规范

**量化表达**：每个创新点必须含 1 个以上量化指标：
- 准确率提升：X% → Y%（绝对值）或 +N%（相对值）
- 速度提升：X 秒 → Y 秒，或缩短 N 倍
- 样本规模：N+ 样本（vs 已有 M 样本）
- 类别覆盖：N 类故障（vs 已有 M 类）
- 成本下降：X 元 → Y 元，或降低 N%

**反例对照**：

❌ "本项目具有创新性：（1）理论创新：首次将深度学习应用于光伏故障检测；（2）方法创新：采用先进的卷积神经网络；（3）应用创新：实现了智能诊断。"
问题：3 个创新点全是空话——"首次"无支撑、"先进"无量化、"实现"非创新。

✅ 见 6.2/6.3/6.4 对应模板示例。

**6 类常见错误模板**：
1. 纯形容词堆砌：❌"采用先进的深度学习方法，具有突出的性能优势"
2. 声称"首次"无支撑：❌"首次将深度学习应用于光伏故障检测"
3. 把"实现"当创新：❌"实现了智能诊断系统的开发"
4. 把"使用工具"当创新：❌"创新性地使用了 Python 编程语言"
5. 把"研究问题"当创新：❌"研究了光伏故障检测问题"
6. 把"采用框架"当创新：❌"创新性地采用 PyTorch 框架"

### 7.1 学生自主性声明

- 研究内容撰写用"项目组""本项目"，不用"指导教师将完成"
- 进度表标注每阶段负责人（团队成员姓名），不写"指导教师"
- 关键实验/调研由团队成员执行，指导教师审核

**申报书末尾可加声明**（部分学校模板要求）：
> 本项目由项目组学生自主设计、自主实施、自主总结，指导教师提供学术指导与技术审核，未代为完成任何研究工作。

### 7.2 过程可追溯要求

每阶段留实验记录/代码提交/调研日志，体现"重在过程"：

| 阶段 | 可追溯材料 | 存档方式 |
|------|-----------|----------|
| 调研 | 文献阅读笔记、调研访谈记录 | 团队共享盘 |
| 数据采集 | 原始数据、标注记录、数据清洗日志 | Git 仓库 |
| 实验 | 实验日志、代码提交记录、模型权重 | GitHub/Gitee |
| 测试 | 测试报告、对比实验记录 | 实验室服务器 |
| 总结 | 论文草稿、专利申请书、结题报告 | 项目归档 |

申报书"前期工作基础"段可提及："项目组已建立 Git 代码仓库与共享文档，全过程留痕，确保研究过程可追溯"。

### 7.3 训练价值体现

"重在过程"强调学生能力提升，申报书须体现团队成员训练价值：

**前期基础段模板**：
> 团队 N 名成员通过本项目预期获得以下能力提升：（1）XX 同学通过 CNN 模型设计掌握深度学习工程实践；（2）XX 同学通过数据采集与标注掌握数据工程方法；（3）XX 同学通过实地测试掌握系统集成与部署能力。项目完成后，团队成员将具备独立开展科研工作的基础能力。

## §8 经费预算（含 8.3 合规硬约束）

### 8.1 预算科目与计算依据

5 类标准科目：

| 科目 | 包含内容 | 计算依据写法 |
|------|----------|--------------|
| 资料费 | 图书、数据库、文献订阅 | 图书 N 本 × M 元 + 数据库 X 元 |
| 调研差旅费 | 实地调研、企业走访 | N 次 × M 元（含交通、住宿） |
| 实验材料费 | 试剂、耗材、设备租赁 | 设备 X 元/月 × Y 月 + 耗材 Z 元 |
| 会议费 | 学术会议、研讨会 | N 次 × M 元（会议名） |
| 印刷复印 | 版面费、报告印刷、装订 | 版面费 X 元 + 印刷 Y 元 |

**禁止行为**：
- 全是整数（如 1000、2000、5000）——评审怀疑没认真做预算
- 无计算依据——评审无法核实
- 合计 ≠ 申请经费字段——直接打回重写

### 8.2 经费总额参考

| 级别 | 推荐区间 | 说明 |
|------|----------|------|
| 国家级 | 10000~20000 元 | 评审专家会按"必要 + 充分"原则审核 |
| 省级 | 5000~10000 元 | 同上 |
| 校级 | 2000~3000 元 | 通常不超 5000 |

预算总额不超推荐区间上限。若实际需更多，需在"计算依据"中明确说明必要性。

### 8.3 经费合规硬约束（5 条，违反直接打回）⭐新增

撰写经费预算时必须遵守以下 5 条硬约束（来源：南昌医学院、海南大学等多校通知）：

**约束 1：差旅费≤总经费 10%**
- 例：总经费 9500 元，差旅费≤950 元
- 违反：差旅费 2600 元（占比 27%）→ 评审打回
- 解决：减少调研次数或改用线上调研

**约束 2：版面费报销须项目组成员为一作/通讯作者**
- 撰写时：在预算依据中注明"版面费用于发表中文核心论文 1 篇，第一作者为负责人张三"
- 若论文一作为非项目组成员，版面费不得报销

**约束 3：不得列支通用办公材料**
- 禁列：复印纸、硒鼓、墨盒、打印机、U 盘等通用办公耗材
- 可列：实验专用耗材（试剂、传感器、电子元件）、专用软件许可
- 例外：报告印刷费（项目结题报告打印）可列，但需注明"项目报告印刷 N 份 × M 元"

**约束 4：设备费单价>1000 元需附采购清单**
- 单价>1000 元的设备/材料，预算依据须写明：型号、单价、数量、用途
- 例："红外热成像仪 FLIR T630，单价 1800 元/月租赁 ×5 月，用于故障样本采集"
- 推荐改用"设备租赁"而非"设备采购"（大创经费一般不支持大额设备采购）

**约束 5：研究生劳务费多数学校禁止（仅本科生）**
- 大创面向本科生，研究生劳务费一般不得列支
- 本科生劳务费：部分学校允许（≤总经费 20%），部分学校禁止
- 撰写时：默认不列劳务费，若用户学校允许则按≤20% 列支并注明"本科生劳务费 X 元 × Y 人 × Z 月"

### 8.4 预算示例（合规版）

| 预算科目 | 金额（元） | 计算依据 | 合规检查 |
|----------|-----------|----------|----------|
| 资料费 | 850 | 图书 15 本 × 50 元 + 数据库订阅 100 元 | ✅ 无办公耗材 |
| 调研差旅费 | 950 | 1 次实地调研 × 950 元（交通+住宿） | ✅ ≤总经费 10%（9500×10%=950） |
| 实验材料费 | 5320 | 红外热成像仪租赁 1800 元/月 × 2 月 + 标注 320 元 + 数据存储 1880 元 | ✅ 单项>1000 已注明型号 |
| 会议费 | 1200 | 全国新能源会议 1 次 × 1200 元 | ✅ |
| 印刷复印 | 1180 | 版面费 1000 元（第一作者为负责人） + 报告印刷 180 元（60 份 × 3 元） | ✅ 版面费一作为负责人 |
| 合计 | 9500 | | ✅ 合计=申请经费 |

### 8.5 反例对照

❌ "资料费 2000 元，调研费 3000 元，材料费 5000 元，合计 10000 元。"
问题：全整数、无依据、差旅占比 30%（超 10% 上限）。

✅ 见 8.4 节预算示例表。每项有计算依据，金额非整数，差旅占比合规。

## §10 立项答辩 PPT 框架（10~12 页）⭐新增大章

立项答辩通常 5~8 分钟讲解 + 3~5 分钟问答。本 skill 提供 PPT 框架（不直接生成 PPT 文件，需用户根据框架制作）。

### 10.1 PPT 结构（10~12 页）

| 页码 | 页面标题 | 内容要点 | 视觉建议 |
|------|----------|----------|----------|
| P1 | 封面 | 项目名称+级别+负责人+指导教师+日期 | 学校 LOGO + 项目名称居中 |
| P2 | 立项背景 | 价值导向开篇 + 时代背景数据 + 现实痛点 | 数据图表（柱状/饼图） |
| P3 | 国内外研究现状 | 已有方案对比表 + 本项目差异点 | 对比表格 |
| P4 | 研究内容 | 3~5 个子任务（图标+一句话） | 流程图/思维导图 |
| P5 | 研究目标 | 总目标 + 阶段目标（可量化） | 时间轴 |
| P6 | 创新点 | 2~3 个创新点（对比式） | 对比柱状图 |
| P7 | 技术路线 | 流程图（5 阶段） | 横向流程图 |
| P8 | 进度安排 | 甘特图/时间表 | 甘特图 |
| P9 | 预期成果 | 4 类成果（数量+级别） | 图标列表 |
| P10 | 团队与基础 | 成员分工表 + 指导教师 + 实验室 | 团队照片/设备图 |
| P11 | 经费预算 | 5 类科目占比饼图 | 饼图 |
| P12 | Q&A 备用页 | 补充数据/对比表/参考文献 | 备用 |

### 10.2 5 分钟时间分配表

| 环节 | 时间 | 页码 | 讲解要点 |
|------|------|------|----------|
| 开场白 | 0.5 分钟 | P1 | 自我介绍 + 项目名称 + 一句话价值定位 |
| 立项背景 | 1.5 分钟 | P2~P3 | 价值导向 + 痛点数据 + 研究空白 |
| 研究内容 | 2.5 分钟 | P4~P5 | 子任务 + 目标（重点讲清"做什么"） |
| 创新点 | 0.2 分钟 | P6 | 一句话讲清 2~3 个创新点（对比+量化） |
| 技术路线 | 0.3 分钟 | P7 | 流程图过一遍（不展开细节） |
| 进度+成果+团队+经费 | 0.5 分钟 | P8~P11 | 快速过（每页 10 秒） |
| 总结 | 0.5 分钟 | 回到 P1/P12 | 一句话总结 + 致谢 |
| **合计** | **5 分钟** | | |

⚠️ 时间分配硬约束：研究内容 2.5 分钟最长，创新点 0.2 分钟最短（一句话带过，细节在问答环节展开）。

### 10.3 开场白 30 秒模板

> 各位评审老师好，我是 XX 学院 XX 专业的 XX，今天汇报的项目是"分布式光伏故障智能诊断系统"，申报国家级大创创新训练项目。
>
> 本项目针对分布式光伏故障检测响应慢（48 小时）、误报率高（20%）的痛点，开发基于深度学习的智能诊断系统，预实验准确率已达 92%，预期将故障响应时间缩短至 1 小时。
>
> 下面从立项背景、研究内容、创新点、技术路线、预期成果五个方面汇报。

### 10.4 问答应对 5 条话术

| 可能问题 | 应对话术 |
|----------|----------|
| Q1：你的方法和已有 XX 论文有什么区别？ | "感谢老师提问。已有 XX 论文使用仿真数据（样本数<1000），本项目使用真实电站 5000+ 样本；已有方法准确率 80%，本项目预实验已达 92%。具体差异在 P3 对比表中。" |
| Q2：技术路线可行性如何保证？ | "技术路线已经过预实验验证：① 已采集 500 样本完成预训练，准确率 92%；② 指导教师李教授主持过国家自然科学基金相关课题；③ 实验室配备 FLIR T630 红外热成像仪与 GPU 服务器。" |
| Q3：经费够用吗？ | "经费 9500 元按 5 类科目分配，差旅 950 元（占 10%）、实验材料 5320 元（含设备租赁 2 个月）、版面费 1000 元、会议 1200 元、资料 850 元，每项有计算依据，可完成全部研究任务。" |
| Q4：团队成员有能力完成吗？ | "团队 4 人专业互补：负责人张三修读过《机器学习》《数字图像处理》；李四有校级大创经验；王五负责硬件搭建；赵六负责数据分析。指导教师每月指导≥2 次。" |
| Q5：成果能产出吗？ | "已与合作企业签署数据协议（5000+ 样本），预实验准确率 92%（论文数据已具备）；原型系统将在企业电站试运行 3 个月；发明专利已与企业协商共同申请。" |

### 10.5 评分标准对照表（参考 §11 A 套）

| 评分维度 | 权重 | PPT 对应页 | 答辩要点 |
|----------|------|-----------|----------|
| 创新性 | 30% | P6 | 一句话讲清对比+量化 |
| 可行性 | 25% | P7+P10+P11 | 流程图+团队+经费 |
| 必要性 | 20% | P2+P3 | 痛点数据+研究空白 |
| 团队协作 | 15% | P10 | 分工表+专业互补 |
| 规范性 | 10% | 全 PPT | 字体统一+无错别字+页码 |

### 10.6 PPT 制作注意事项

- 字体：标题黑体 32pt，正文宋体 24pt（投影清晰）
- 配色：≤3 色（学校主色 + 灰 + 强调色）
- 图表：每页至少 1 个图表（数据/流程/对比），纯文字页评审不看
- 动画：禁用复杂动画（评审时间紧，每页 10~30 秒）
- 备用页：P12 准备 3~5 张补充数据页，应对追问

### 10.7 答辩避坑 5 条

| 坑 | 问题 | 解决 |
|----|------|------|
| 坑 1：超时 | 讲到创新点时被中断 | 严格按 5 分钟时间分配表，提前用秒表计时 |
| 坑 2：念 PPT | 评审觉得没消化内容 | 讲"为什么"和"怎么做"，不念 PPT 文字 |
| 坑 3：被问倒 | 创新点量化数据答不上 | 准备 §10.4 的 5 条话术 + 备用数据页 |
| 坑 4：贬低他人 | 说"已有研究都很差" | 用"已有研究存在 XX 局限"中性表述 |
| 坑 5：过度承诺 | 说"一定能发 SCI" | 说"拟投《XX》，预实验数据已具备投稿条件" |

### 10.8 答辩着装与礼仪

- 着装：正装或校服，避免 T 恤短裤
- 站位：站在投影屏侧前方，不挡屏幕
- 眼神：与 3 位评审轮流眼神交流，不盯着屏幕
- 语速：每分钟 200~240 字，关键数据放慢
- 手势：手势不超过肩膀宽度，不插兜

| 目标明确性 | 研究目标清晰、可量化、可达成 |
| 训练内容清晰度 | 研究内容具体、方法明确、过程可追溯 |

⚠️ C 套不按权重打分，按"通过/不通过"导向性评审。北师大等校申报时须重点打磨价值导向开篇句（§5）与训练价值体现（§7.3）。

### 11.4 评审标准选择规则

**明确标注"以本校实际通知为准，本 skill 默认 A 套"**。

撰写前询问用户："学校评审标准是 A/B/C 哪一套？若不确定按 A 套默认处理。"

- A 套：西南大学、合肥工业大学、清华大学、浙江大学等多数 985/211
- B 套：海南大学等部分省属高校
- C 套：北京师范大学等导向性评审学校

### 11.5 评审流程与立项率

- 评审专家 3 人/项目，独立打分取平均
- 平均分排序，按名额录取
- 评审时长：每份约 10~15 分钟（评审没时间读空话）
- 立项率（见 §2.2）：国家级 10%~15%，省级 20%~30%，校级评审通过率 30%~50%

### 11.6 高分/低分申报书特征

**高分特征**：
- 项目名称 ≤25 字，突出"做什么 + 为谁做"
- 项目简介 4 句话讲完整，无空话
- 立项背景每段有数据，价值导向开篇
- 创新点有对比 + 有量化
- 技术路线有流程图
- 进度表按月划分，每阶段有交付物
- 预期成果数量 + 级别 + 平台齐全
- 预算每项有计算依据，合规硬约束全过
- 团队成员有分工 + 专业 + 年级
- 全文无错别字、无格式错误

**低分特征**（任一即扣大分）：
- 项目名称堆"基于...的..."超 25 字
- 项目简介全是背景铺垫
- 创新点写"具有创新性"
- 技术路线纯文字无流程图
- 进度表写"前期/中期/后期"
- 预期成果写"若干"
- 预算全整数无依据，差旅占比超 10%
- 团队成员只写姓名不分工
- 研究现状简单罗列不评述
- 全文错别字超过 3 处

### 11.7 评分计算示例（A 套）

假设 3 位评审专家打分：

| 维度 | 权重 | 专家 A | 专家 B | 专家 C | 平均 | 加权得分 |
|------|------|--------|--------|--------|------|----------|
| 创新性 | 30% | 85 | 80 | 90 | 85.0 | 25.5 |
| 可行性 | 25% | 80 | 75 | 85 | 80.0 | 20.0 |
| 必要性 | 20% | 75 | 80 | 85 | 80.0 | 16.0 |
| 团队协作 | 15% | 85 | 85 | 80 | 83.3 | 12.5 |
| 规范性 | 10% | 90 | 85 | 90 | 88.3 | 8.8 |
| 合计 | 100% | - | - | - | - | 82.8 |

最终得分 82.8 分。国家级录取线通常 80+，省级 75+，校级 70+。

## §13 金句模板（8 句，按栏目顺序）

撰写时可直接套用以下金句模板，确保每段有数据、有量化、有结构。

### 13.1 项目简介开篇

> 本项目针对 [具体场景] 中 [量化痛点] 的问题，[开发/构建] [项目核心名词]，通过 [核心方法] 实现 [量化目标]，预期产出 [数量+级别+载体]。

**示例**：
> 本项目针对分布式光伏故障检测中响应慢（48 小时）、误报率高（20%）的问题，开发基于卷积神经网络的智能诊断系统，通过多模态融合实现 8 类故障识别（准确率≥95%），预期产出 1 套原型系统、1 篇中文核心论文、1 项发明专利。

### 13.2 立项背景-时代背景开篇（价值导向）

> 本项目选题响应我国『[国家战略]』战略导向，契合 [具体政策/文件] 要求。2024 年 [行业规模/装机量] 突破 [数据]（[权威数据来源]），年均增速 [X]% 以上。

**示例**：
> 本项目选题响应我国"双碳"战略导向，契合《"十四五"现代能源体系规划》要求。2024 年分布式光伏装机量突破 6 亿千瓦（国家能源局数据），年均增速 35% 以上。

### 13.3 立项背景-现实痛点

> 调研 [N] 家 [企业/单位] 发现，[环节] 主要依赖 [传统方式]，平均 [响应时长/成本] 达 [X]，[损失比例] 高达 [Y]%，单 [户/次] 年损失 [金额] 元。

**示例**：
> 调研 XX 省 3 家光伏运维企业发现，分布式光伏故障检测主要依赖人工巡检，平均响应时间超过 48 小时，故障期间发电损失达 5%~8%，单户年损失超 800 元。

### 13.4 国内外研究现状评述

> 已有研究（[作者 年份]，[作者 年份]）主要基于 [传统方法]，存在 [具体局限]，准确率约 [X]%；近年 [作者 年份] 尝试引入 [新方法]，但 [数据集/场景/规模局限]。本项目关键差异在于：（1）[差异 1]；（2）[差异 2]。

**示例**：
> 已有研究（Smith 2020，Wang 2021）主要基于 SVM、决策树，依赖人工特征提取，准确率约 75%~80%；近年 Zhang (2022) 尝试引入深度学习，但数据集多为实验室仿真。本项目关键差异在于：（1）使用真实电站 5000+ 样本；（2）覆盖 8 类典型故障（已有研究多覆盖 3~5 类）。

### 13.5 创新点对比式

> 创新点 N：[方法/技术/数据/视角/模式/设计/成本/功能/落地] 创新。传统/已有方法 [具体做法]，[量化局限 X]；本项目采用 [具体方法]，预实验显示 [量化优势 Y]，相比传统方法 [相对提升 Z]。

**示例**：
> 创新点 1：方法创新。传统光伏故障检测依赖人工特征提取（准确率约 80%），本项目采用端到端 ResNet-50 残差网络自动学习故障特征，预实验准确率已达 92%，相比传统方法提升 12 个百分点。

### 13.6 项目意义三角度

> 理论上，探索 [方法] 在 [小样本/多类别/复杂场景] 中的适用边界；实践上，与 [合作单位] 合作开发 [可落地成果]，预期将 [指标] 从 [X] 缩短/提升至 [Y]，单 [户/次] [增收/节约] [金额] 元；社会上，助力 [国家战略/乡村振兴/双碳] 目标实现。

**示例**：
> 理论上，探索深度学习在小样本、多类别故障诊断中的适用边界；实践上，与 XX 公司合作开发可落地的诊断系统，预期将故障响应时间从 48 小时缩短至 1 小时，单户年增收约 600 元；社会上，助力乡村振兴与"双碳"目标实现。

### 13.7 可行性收尾

> 团队 [N] 名成员已修读 [核心课程 1]、[核心课程 2]，[N] 人有校级大创参与经验，专业覆盖 [专业 1]/[专业 2] 互补。指导教师 [姓名] 主持 [国家级/省部级项目] [N] 项，近 3 年发表 [SCI/核心] 论文 [N] 篇。实验室配备 [设备型号+数量]，技术路线经预实验 [N] 样本验证可行。

**示例**：
> 团队 4 名成员已修读《机器学习》《数字图像处理》，3 人有校级大创参与经验，专业覆盖电气工程/计算机科学互补。指导教师李教授主持国家自然科学基金 1 项，近 3 年发表 SCI 论文 5 篇。实验室配备红外热成像仪 FLIR T630、GPU 服务器（RTX 4090 ×4），技术路线经预实验 500 样本验证可行。

### 13.8 预期成果可量化

> [中文核心/SCI] 期刊论文 [N] 篇（拟投《[期刊名]》，第一作者为负责人）；[发明/实用新型] 专利申请 [N] 项（与合作单位共同申请，学生为第一发明人）；[原型/产品] 系统 [N] 套（部署在 [合作单位] 试运行 [N] 个月）；调研/研究报告 [N] 份（约 [N] 万字）。

**示例**：
> 中文核心期刊论文 1~2 篇（拟投《电力系统自动化》，第一作者为负责人）；发明专利申请 1 项（与合作企业共同申请，学生为第一发明人）；原型系统 1 套（部署在 XX 电站试运行 3 个月）；调研报告 1 份（约 2 万字）。

## §15 红线规则与免责声明

### 15.1 红线规则（违反即拒绝生成）

| 红线 | 说明 | 后果 |
|------|------|------|
| 编造数据/作者/期刊名 | 不得虚构统计数据、文献作者、期刊名称 | 拒绝生成，要求用户提供真实数据 |
| 把创业训练内容混入创新训练 | 不得在创新训练申报书出现"商业模式""盈利预测""融资" | 触发后告知用户走创业训练 skill |
| 项目名称超 25 字 | 评审硬扣分 | 强制精简后再生 |
| 预算合计 ≠ 申请经费字段 | 评审直接打回 | 强制修正后再生 |
| 差旅费占比超 10% | 违反合规硬约束（§8.3） | 强制调整后再生 |
| 创新点无对比对象 | 创新点不成立 | 追问到有对比后再生 |
| 预期成果写"若干" | 不可量化 | 追问到具体数量+级别后再生 |
| 用"我们""我" | 申报书用第三人称 | 全文替换为"本项目""项目组" |
| 列支研究生劳务费 | 多数学校禁止 | 删除该科目后再生 |
| 列支通用办公耗材 | 违反 §8.3 约束 3 | 删除后再生 |
| 缺指导频次声明 | 海南大学等校硬要求 | 插入默认声明后再生 |
| 缺知识产权归属声明 | 部分学校硬要求 | 插入默认声明后再生 |

### 15.2 免责声明

- 本 skill 按"国家级模板（A 套评审标准）"默认处理，**学校实际通知与本 skill 不一致时以学校通知为准**
- 评审标准 3 套对照（A/B/C）仅供参考，具体权重以本校下发通知为准
- 经费合规硬约束基于南昌医学院、海南大学等多校通知整理，**具体以本校财务规定为准**
- 立项率数据（10%~15%/20%~30%/30%~50%）为行业经验值，**不编入申报书正文**
- 知识产权归属声明为默认模板，**部分学校有专门模板需替换**

### 15.3 学校差异处理

不同学校模板有微调，处理规则：

**栏目顺序差异**：个别学校把"经费预算"放在"研究内容"后，或合并"指导教师意见"与"学院意见"。按学校下发模板顺序调整 build.py 的 build() 方法调用顺序。

**字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。

**页边距差异**：部分学校要求 3cm 左右边距。修改 build.py setup_page() 中的 left_margin/right_margin。

**栏目增减**：
- 校级通常无"学校审批意见"栏 → `include_school_approval=False`
- 部分学校增加"中期检查计划"栏 → 在 build() 中追加 _add_midterm_check() 方法
- 部分学校要求"学术诚信承诺"栏 → 在签字栏前追加

**级别差异**：
- 国家级：12 栏目全要 + 经费 1~2 万 + 至少 3 个创新点
- 省级：12 栏目全要 + 经费 5 千~1 万 + 至少 2 个创新点
- 校级：可省"学校审批意见"栏 + 经费 2~3 千 + 至少 1 个创新点

适配流程：先问"学校下发的模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按国家级模板处理。

适配完成后告知用户"已按 XX 学校模板调整，请核对栏目顺序与字体"。

### 15.4 常见学校差异速查

### 15.6 字数自动检查脚本

撰写完成后用以下脚本核对各栏目字数：

```python
import re
text = open('output.txt').read()
sections = {
    '项目简介': extract_section(text, '二、项目简介', '三、'),
    '立项背景': extract_section(text, '三、立项背景', '四、'),
    '研究内容': extract_section(text, '四、项目研究内容', '五、'),
    '创新点': extract_section(text, '五、项目创新点', '六、'),
    '技术路线': extract_section(text, '六、技术路线', '七、'),
    '前期基础': extract_section(text, '十、前期工作基础', '十一、'),
}
limits = {
    '项目简介': (300, 500), '立项背景': (800, 1200),
    '研究内容': (800, 1200), '创新点': (400, 600),
    '技术路线': (500, 800), '前期基础': (300, 500),
}
for name, content in sections.items():
    n = len(re.sub(r'[\s\W]', '', content))
    lo, hi = limits[name]
    status = '✅' if lo <= n <= hi else '❌'
    print(f'{status} {name}: {n} 字（{lo}~{hi}）')
```
