# 大创-创业训练项目申报书 Skill

本 skill 处理"大学生创新创业训练计划-创业训练项目"申报书全流程：信息采集 → 商业内容撰写 → docx 生成 → 质检。仅处理"创业训练"子类（商业计划书型），不要求实际注册公司；区别于创新训练（学术研究型）与创业实践（实际运营型）。

输出文件：可提交的 .docx（A4 纸张，宋体小四正文，黑体三号标题，1.5 倍行距，首行缩进 2 字符）。

---

## 一、适用场景与触发条件

**适用**：用户提到"大创""创业训练项目""大学生创业训练""国家级/省级/校级创业训练申报书""商业计划书型大创"等关键词，且项目产出为商业计划书 / 模拟运营报告 / 路演材料（非学术论文、非已注册公司报表）。

**不适用**（走其他 skill）：
- 创新训练项目（产出论文/研究报告）→ 走创新训练 skill
- 创业实践项目（已注册公司或运营 6 个月以上）→ 走创业实践 skill
- "互联网+"大赛、挑战杯创业赛道 → 走竞赛类 skill
- 校级科研立项 → 走科研立项 skill

**触发后第一步**：确认项目类型为"创业训练"。区分要点：
- 创新训练：偏学术，研究方法/视角创新，产出论文
- 创业训练：偏商业，商业模式/产品形态创新，产出商业计划书，**不要求实际注册公司**
- 创业实践：已注册公司或运营 6 个月以上，有真实营收数据

用户未明确时，按"是否要注册公司"区分——要注册走创业实践，不注册走创业训练。

---

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（12~18 轮对话）**：
按"通用必采 → 商业专属 → 团队成员 → 指导教师 → 市场分析素材 → 商业模式素材 → 财务预测素材 → 风险与成果"顺序采集。每轮不超过 5 个字段。商业字段（TAM/SAM/SOM、CAC/LTV、定价、毛利）缺失必须追问，禁止编造市场数据。

**阶段 2 内容撰写（一次性产出）**：
按 13 栏目顺序撰写。商业模式画布必须 9 要素齐全，财务预测必须 3 年表格，竞品分析必须有对比矩阵。预期成果以商业计划书 / 模拟运营报告为主，可附路演 PPT。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十二章。

**阶段 4 质检**：
按第十三章 18 项清单逐项检查。任何一项不达标返回阶段 2 修改。

**禁止行为**：
- 跳过采集直接套模板
- 编造市场规模、竞品数据、用户数、营收
- 用"前景广阔""意义重大""颠覆性"等空话
- 把学术研究内容（文献综述、技术路线流程图）混入创业训练申报书
- 把"已注册公司""实际营收 100 万"等创业实践特征写入创业训练申报书
- 商业模式画布少要素（必须 9 个齐全）

| 字段 | 说明 | 示例 |
|------|------|------|
| project_type | 三选一 | 创业训练项目 |

| duration | 起止时间 | 2025.04-2026.03（12 个月） |

### 3.3 市场分析素材

- 行业规模数据（TAM 总市场容量，需权威来源：艾瑞/IDC/国家统计局/行业白皮书）
- 可服务市场 SAM（项目能覆盖的细分市场，按地域/人群/场景切分）
- 可获取市场 SOM（项目 1~3 年实际可拿到的份额，通常为 SAM 的 1%~10%）
- 3~5 个直接竞品 + 2~3 个间接竞品，每个含：名称/定位/用户规模/融资阶段/优劣势
- 用户访谈记录（建议访谈 10+ 目标用户，记录痛点、付费意愿、价格敏感度）

### 3.4 商业模式素材

- 商业模式画布 9 要素：客户细分 / 价值主张 / 渠道通路 / 客户关系 / 收入来源 / 核心资源 / 关键业务 / 重要伙伴 / 成本结构
- 盈利模式：交易抽佣 / 订阅会员 / 增值服务 / 广告 / 数据服务 / SaaS 月费，至少 1 类清晰
- 定价策略：单次/月度/年度价格，对照竞品定价与用户付费意愿
- CAC（获客成本）估算：单用户获客成本 = 推广预算 / 预期新增用户
- LTV（用户生命周期价值）估算：客单价 × 复购次数 × 毛利率

### 3.5 财务预测素材

- 3 年营收预测（按月或按季度，第一年细，后两年粗）
- 3 年成本结构（固定成本：人员/办公/服务器；变动成本：获客/履约/客服）
- 毛利率估算（行业平均 + 项目实际）
- 盈亏平衡点（用户数 / 月营收达到多少时不再亏损）
- 启动资金需求（含大创经费 + 自筹 + 拟融资额）

### 3.6 字段优先级

| 优先级 | 字段 | 缺失影响 |
|--------|------|----------|
| P0 必填 | project_name/leader_name/leader_id/college/advisor_name | 申报书无法生成 |
| P0 必填 | project_type/industry/duration/budget_total/target_user | 基本信息表不完整 |
| P0 必填 | abstract/market_analysis/business_model/financial_forecast | 核心栏目空白 |
| P1 强烈建议 | team_members（含分工）/competitors/business_canvas/risks | 评审会扣分 |
| P2 建议 | operations_plan/team_foundation/advisor_foundation | 影响评分但可补 |
| P3 可选 | user_research_data/patent_status | 看学校模板是否要求 |

P0 缺失：必须追问到底，不允许"先放空"。P1 缺失：追问 2 次，仍无则用合理默认值并告知用户。P2/P3 缺失：1 次追问后无则跳过。

### 3.7 追问话术

| 场景 | 话术 |
|------|------|
| 市场规模无来源 | "TAM 数据来源是？艾瑞/IDC/国家统计局？请提供链接或报告名" |
| 竞品只写名字 | "竞品 XX 的用户规模、融资阶段、优劣势分别是什么？" |
| 商业模式只写"卖产品" | "盈利模式具体是？单次购买 / 订阅 / 抽佣 / 增值服务？客单价多少？" |
| 财务预测无依据 | "Year1 营收 50 万的算法是？用户数 × 客单价 = 营收，请给具体数" |
| CAC/LTV 缺失 | "获客成本估算多少？用户生命周期价值估算多少？LTV/CAC 比建议 ≥3" |
| 团队全是同专业 | "团队成员有商科 + 技术 + 设计复合吗？纯商科团队技术落地难" |
| 写"市场广阔" | "广阔具体是多少亿？请给数据" |

### 3.8 复述确认

全部采集完后，按申报书栏目顺序复述给用户：
"已采集所有信息，按申报书顺序复述：① 项目名称 ② 负责人 ③ 行业 ④ 目标用户 ⑤ TAM/SAM/SOM ⑥ 商业模式画布 9 要素 ⑦ 3 年财务预测 ⑧ 竞品 ⑨ 风险 ⑩ 预期成果。请确认或补充修正。"

用户确认后才进入撰写阶段。任何字段"待定""之后再说"——必须当场追问，不允许留空。

## 四、栏目结构详解

国家级创业训练模板 13 栏目，省级/校级结构基本一致（个别栏目顺序或合并）。下文按国家级顺序展开。

### 4.1 封面

```
国家级大学生创新创业训练计划项目申报书
（创业训练项目）

项目名称：________________
项目负责人：________________
指导教师：________________
所在学院：________________
申报日期：________________
```

封面 6 字段：标题（黑体二号居中）+ 副标题（项目类型）+ 5 行信息（黑体四号标签 + 宋体四号下划线内容）。封面后插分页符。

### 4.2 一、基本信息（表格）

9 行 2 列表格：

| 项目 | 内容 |
|------|------|
| 项目名称 | 校园闲置物品流转平台"易舍" |
| 项目类型 | 创业训练项目 |
| 项目来源 | A 学生自主选题 |
| 所属行业 | 互联网/二手交易 |
| 起止时间 | 2025.04-2026.03（12 个月） |
| 申请经费 | 10000 元 |
| 负责人 | 张三 / 202212345 / 工商管理 / 大三 / 138XXXXXXXX |
| 团队成员 | 李四（产品经理）、王五（前端开发）、赵六（市场运营）、孙七（UI 设计） |
| 指导教师 | 李教授 / 副教授 / 创业管理 / 139XXXXXXXX |

负责人行格式："姓名 / 学号 / 专业 / 年级 / 联系方式"。团队成员行格式："姓名（分工）、姓名（分工）..."，必须含分工。

### 4.3 二、项目简介（300~500 字）

一段成文，4 句结构：
- 第 1 句：市场机会 + 做什么（"针对 XX 市场 XX 痛点，开发 XX 产品/平台"）
- 第 2 句：怎么做 + 量化目标（"通过 XX 模式，服务 XX 用户，预期月活 X 万，年营收 X 万"）
- 第 3 句：商业模式 + 产出（"采用 XX 盈利模式，预期产出商业计划书 1 份、模拟运营报告 1 份、MVP 1 套"）
- 第 4 句：现状（"项目已完成用户调研 50 份、MVP 原型上线、首批 200 内测用户"）

完整示例（约 350 字）：
> 本项目针对高校校园闲置物品流转效率低、传统跳蚤市场信息不对称的痛点，开发基于微信小程序的校园闲置物品流转平台"易舍"。通过 LBS + 校园认证 + 信用积分机制，服务高校 18~24 岁在校生，预期上线 6 个月覆盖本市 5 所高校、月活 5000+、年交易额 50 万元。采用"交易抽佣 5% + 增值会员 9.9 元/月"盈利模式，预期产出商业计划书 1 份、模拟运营报告 1 份、MVP 1 套、用户调研报告 1 份。项目已完成 50 份用户调研、MVP 原型上线、首批 200 名内测用户、3 家高校社团合作意向。

字数控制：少于 300 字评审觉得没分量；多于 500 字评审抓不住重点。

### 4.4 三、行业背景与市场分析（800~1200 字，4 段 + 表格）

- **行业背景**（150~200 字）：3 句话，行业规模/增速/政策导向，必须有权威数据来源
- **目标市场（TAM/SAM/SOM）**（200~300 字）：3 级市场测算，必须含表格
- **竞品分析**（200~300 字）：3~5 个直接竞品 + 2~3 个间接竞品，必须含对比表
- **用户画像与需求验证**（200~300 字）：典型用户画像 1~2 个 + 用户访谈结论

完整示例：

**行业背景**：2024 年中国二手交易市场规模达 5000 亿元（艾瑞咨询《2024 中国二手电商报告》），年均增速 20%+，其中校园场景占比约 5%（约 250 亿元）。国家发改委 2024 年《促进绿色消费实施方案》明确鼓励校园二手物品循环利用。

**目标市场（TAM/SAM/SOM）**：

| 层级 | 定义 | 规模 |
|------|------|------|
| TAM 总市场 | 全国高校在校生 4700 万，人均年闲置物品消费 530 元 | 250 亿元/年 |
| SAM 可服务市场 | 本省 50 所高校 120 万在校生 | 6.4 亿元/年 |
| SOM 可获取市场（3 年内） | 本市 5 所高校 12 万在校生，预期渗透率 20% | 1272 万元/年 |

**竞品分析**：

| 竞品 | 定位 | 用户规模 | 优势 | 劣势 |
|------|------|----------|------|------|
| 闲鱼 | 全品类二手 | 5 亿注册 | 流量大、品牌强 | 校园场景弱、信任度低 |
| 转转 | 数码 3C 二手 | 2 亿注册 | 验机服务完善 | 非校园场景 |
| 校园跳蚤市场群 | 线下/微信群 | 不可统计 | 信任度高 | 信息散乱、效率低 |

本项目差异化：聚焦校园场景、LBS 同校交易、信用积分体系。

**用户画像与需求验证**：典型用户"小张"，大三在校生，月生活费 2000 元，每年闲置物品价值约 500 元，曾尝试闲鱼但因跨城交易邮费高、面交难放弃。访谈 50 名目标用户，42 人表示愿意为"同校面交 + 信用背书"付费，付费意愿 9.9 元/月接受度 68%。

### 4.5 四、产品或服务介绍（500~800 字，3 子节）

**（一）产品形态**：MVP 功能清单（5~8 个核心功能），每个含名称 + 解决什么问题 + 关键指标。
**（二）核心功能演示**：1~2 个核心功能详细描述，含用户操作流程。
**（三）技术实现**：技术架构（前端/后端/数据库）、关键第三方服务、研发投入估算。

产品形态示例：
> 1. **校园认证**：学信网/校园邮箱认证，解决陌生人交易信任问题，预期认证率 ≥80%。
> 2. **LBS 同校匹配**：基于地理位置匹配同校买卖双方，预期面交转化率 ≥60%。
> 3. **信用积分**：交易评价 + 实名认证 + 校园认证累计积分，积分高者优先展示。
> 4. **一键发布**：拍照识别 + AI 描述生成，发布时间从 5 分钟降至 30 秒。
> 5. **担保交易**：买家确认收货后打款，降低交易风险。

技术实现示例：
> 前端：微信小程序（Taro 3.x）；后端：Node.js + Express；数据库：MySQL 8.0 + Redis 7.0；第三方：腾讯云 LBS、阿里云 OSS、微信支付。研发投入：3 人 × 4 月 = 12 人月，约 6 万元（按校内外包价折算）。

### 4.6 五、商业模式（500~800 字 + 9 宫格画布）

**（一）商业模式画布**：9 宫格表格，每格 30~50 字。

| 客户细分 | 价值主张 | 渠道通路 |
|----------|----------|----------|
| 高校 18~24 岁在校生，月生活费 1500~3000 元 | 同校面交、信用背书、一键发布 | 微信小程序、校园社团合作、社群裂变 |
| **客户关系** | **收入来源** | **核心资源** |
| 自助服务 + 社群运营 + 客服介入 | 交易抽佣 5% + 增值会员 9.9 元/月 + 广告位 | 小程序代码、用户数据、校园合作关系 |
| **关键业务** | **重要伙伴** | **成本结构** |
| 产品开发、用户运营、商家拓展 | 高校社团、腾讯云、顺丰快递 | 服务器 1500/月、获客 5 元/人、人力 0（学生） |

**（二）盈利模式**：列明 1~3 种收入来源，每种含定价 + 计算依据 + 占比预估。
**（三）定价策略**：对照竞品定价 + 用户付费意愿 + 成本加成。

盈利模式示例：
> 1. **交易抽佣**：每笔成交收取 5% 服务费，参考闲鱼免费、转转 1%，本项目因校园场景溢价定 5%。预期 Year1 占营收 70%。
> 2. **增值会员**：9.9 元/月，含优先展示、信用加权、免抽佣券。访谈数据显示 68% 用户接受。预期 Year1 占营收 20%。
> 3. **校园商家广告**：本地商家投放，CPM 50 元。预期 Year1 占营收 10%。

### 4.7 六、运营方案（500~800 字，3 子节 + 表格）

## 五、各栏目撰写规范

### 5.1 字数硬规范

| 栏目 | 字数 | 容差 |
|------|------|------|
| 项目简介 | 300~500 字 | ±50 |
| 行业背景与市场分析 | 800~1200 字 | ±100 |
| 产品或服务介绍 | 500~800 字 | ±50 |
| 商业模式 | 500~800 字 | ±50 |
| 运营方案 | 500~800 字 | ±50 |
| 财务预测 | 表格 + 200~300 字说明 | - |
| 团队介绍 | 300~500 字 | ±50 |
| 风险分析 | 400~600 字 | ±50 |

字数不含标点与表格。低于下限说明内容不充实，高于上限评审难抓住重点。

### 5.2 句式规范

**行业背景**：用"3+2"写法——3 句话讲行业规模/增速/政策，2 句话讲细分市场痛点。每句必须有主语 + 数据/事实。

❌ "二手交易市场具有广阔前景"（无数据、无来源）
✅ "2024 年中国二手交易市场规模达 5000 亿元（艾瑞咨询《2024 中国二手电商报告》），年均增速 20%+，其中校园场景占比约 5%"（有数据、有来源）

**价值主张**：用"为 [谁] 解决 [什么问题] 通过 [什么方式]"句式。

✅ "为高校在校生解决闲置物品流转效率低的问题，通过 LBS 同校面交 + 信用积分机制实现信任交易。"

**竞品分析**：必须用对比表，每行竞品 5 列（名称/定位/用户规模/优势/劣势）。无量化数据的竞品行作废。

**财务预测**：必须 3 年表格 + 文字说明盈亏平衡点。无表格不通过。

### 5.3 数据优先

- 行业规模：标注来源（艾瑞/IDC/国家统计局/行业白皮书）
- 用户规模：标注来源（QuestMobile/极光/自调研）
- 财务数据：标注算法（用户数 × 客单价、客单价 × 复购 × 毛利率）
- 竞品数据：标注来源（竞品官网/财报/36 氪/虎嗅）
- 用户调研：标注样本量（如 N=50）

### 5.4 禁用空话

禁用以下无量化支撑词：
- "市场广阔""前景巨大""意义重大""颠覆性""革命性"
- "用户众多""需求旺盛""反响热烈"
- "先进的技术""高效的运营""智能的产品"
- "相关领域""若干用户""一定规模"

### 5.5 数字与单位

- 金额写"5000 亿元"或"5000 亿"，不写"五千亿"
- 百分比写"20%+"，不写"百分之二十多"
- 用户数写"4700 万"，不写"四千七百万"
- 表格内数字右对齐，正文数字用阿拉伯数字

### 5.6 序号体系

严格使用以下层级：

```
一、（一级，中文数字 + 顿号）
（一）（二级，中文数字 + 括号）
1.（三级，阿拉伯数字 + 点）
（1）（四级，阿拉伯数字 + 括号）
①（五级，带圈数字）
```

### 5.7 段落衔接

每段首句承接上段尾句，不要跳跃。行业背景→市场分析→竞品→用户画像→产品→商业模式→运营→财务，环环相扣。

### 5.8 颜色与高亮

docx 输出全文黑色字体。禁止用红/黄/绿等彩色字体强调，禁止用黄色高亮。评审打印黑白稿，彩色信息会丢失。如需强调，用数据本身（如"5000 亿""20%+"），不用格式。

### 5.9 时态统一

- 行业背景：用过去/现在时（"2024 年市场规模达..."）
- 商业模式：用现在时（"本项目采用..."）
- 财务预测：用将来时（"Year2 营收预计达..."）
- 风险分析：用条件式（"若 X 发生，则 Y"）

### 5.10 第三人称

用"本项目""项目组""平台"，不用"我们""我"。

### 5.11 标点

- 中文标点全角："，。：；！？（）【】《》"
- 不混用中英文标点
- 引号用""（中文双引号），不用 "" 或 ''
- 省略号用"……"不用"..."

## 六、商业模式撰写方法

### 6.1 商业模式画布 9 要素

9 宫格表格，每格 30~50 字，缺一不可：

| 要素 | 内容 | 撰写要点 |
|------|------|----------|
| 客户细分 | 服务谁？1~3 类目标客户 | 写明人群 + 场景 + 规模，如"高校 18~24 岁在校生" |
| 价值主张 | 解决什么问题？提供什么价值 | 用"为 X 解决 Y 通过 Z"句式 |
| 渠道通路 | 怎么接触到客户？ | 线上（小程序/APP/社群）+ 线下（社团/活动） |
| 客户关系 | 怎么保持关系？ | 自助服务 / 社群运营 / 客服介入 / 专属顾问 |
| 收入来源 | 怎么赚钱？ | 交易抽佣 / 订阅会员 / 增值服务 / 广告 / 数据 |
| 核心资源 | 关键资源是什么？ | 代码 / 数据 / 品牌 / 合作关系 / 资质 |
| 关键业务 | 必须做哪些事？ | 产品开发 / 用户运营 / 商家拓展 / 内容生产 |
| 重要伙伴 | 谁是合作伙伴？ | 上游供应商 / 渠道方 / 技术服务方 / 战略合作 |
| 成本结构 | 钱花在哪？ | 固定成本（人力/服务器/办公）+ 变动成本（获客/履约/客服） |

### 6.2 盈利模式设计

5 类常见盈利模式：

| 模式 | 适用场景 | 计算公式 | 案例 |
|------|----------|----------|------|
| 交易抽佣 | 平台型（电商/招聘/O2O） | GMV × 抽佣率 | 闲鱼、滴滴 |
| 订阅会员 | 内容/工具型 | 用户数 × ARPU × 月数 | Netflix、Notion |
| 增值服务 | 基础免费 + 高级付费 | 付费用户数 × 单价 | LinkedIn、百度网盘 |
| 广告变现 | 流量型 | DAU × 人均广告曝光 × eCPM | 抖音、微信朋友圈 |
| 数据服务 | B 端型 | 企业数 × 年费 | 阿里云、TalkingData |

至少 1 类清晰，至多 3 类组合。每类写明：定价 + 计算依据 + Year1 占营收比。

### 6.3 定价策略

3 类定价方法：

**① 成本加成**：成本 ×（1 + 毛利率）。适合硬件/实物商品。
**② 竞品对标**：参考竞品定价 ± 差异化溢价。适合互联网产品。
**③ 用户价值**：基于用户付费意愿调研定价。适合 SaaS/订阅。

定价表必须含：单品价格 / 月费 / 年费 / 竞品对照 / 用户付费意愿（调研数据）。

### 6.4 商业模式反例

❌ "本项目采用创新的商业模式，通过多元化的盈利渠道实现商业价值。"
问题：无具体模式、无定价、无计算依据。

✅ "本项目采用'交易抽佣 5% + 增值会员 9.9 元/月'双轨盈利模式。抽佣参考闲鱼 0%、转转 1%，因校园场景溢价定 5%；会员定价基于 50 份用户调研，68% 用户接受 9.9 元/月。Year1 营收预测 12 万元，其中抽佣占 70%、会员占 20%、广告占 10%。"

### 6.5 PMF 验证

PMF（Product-Market Fit）验证必备 3 项：
- 用户调研：N≥50，付费意愿明确
- MVP 上线：核心功能可用，注册用户 ≥500
- 留存数据：次日留存 ≥30%、7 日留存 ≥15%

申报书中至少展现前 2 项数据，第 3 项可写"预期"。

### 6.6 商业模式画布检查清单

每个画布撰写完后，逐项自检：
- 9 要素是否齐全？
- 客户细分是否具体到人群+规模？
- 价值主张是否用"为 X 解决 Y 通过 Z"句式？
- 收入来源是否含具体定价？
- 成本结构是否分固定/变动？
- 是否避免了"多元化""创新性"等空话？

## 七、市场分析方法

### 7.1 TAM/SAM/SOM 三级测算

| 层级 | 定义 | 测算方法 |
|------|------|----------|
| TAM 总市场 | 整个行业的总规模 | 自上而下：行业报告数据 |
| SAM 可服务市场 | 项目能覆盖的细分市场 | TAM × 细分比例（地域/人群/场景） |
| SOM 可获取市场 | 项目 1~3 年实际可拿到的份额 | SAM × 预期渗透率（通常 1%~10%） |

测算示例：
- TAM：全国高校在校生 4700 万 × 人均年闲置消费 530 元 = 250 亿元/年（数据源：教育部 2024 教育公报 + 自调研）
- SAM：本省 50 所高校 120 万在校生 × 530 元 = 6.4 亿元/年
- SOM：本市 5 所高校 12 万在校生 × 530 元 × 渗透率 20% = 1272 万元/年

### 7.2 竞品分析矩阵

至少 3 个直接竞品 + 2 个间接竞品，每个含 5 列：

| 竞品 | 定位 | 用户规模 | 优势 | 劣势 |
|------|------|----------|------|------|
| 闲鱼 | 全品类二手 | 5 亿注册 | 流量大、品牌强 | 校园场景弱 |
| 转转 | 数码 3C | 2 亿注册 | 验机服务完善 | 非校园场景 |
| 校园跳蚤群 | 线下/微信 | 不可统计 | 信任度高 | 信息散乱 |

用户规模数据必须标注来源（竞品官网/财报/第三方报告）。

### 7.3 用户画像

每个目标用户群撰写 1 个画像，含 6 要素：
- 基本信息：性别 / 年龄 / 职业 / 月收入
- 行为特征：使用场景 / 频次 / 偏好渠道
- 痛点：当前方案的不满
- 需求：理想方案的期望
- 付费意愿：可接受价格区间
- 决策因素：选择产品时最看重什么

画像示例：
> 小张，男，21 岁，大三在校生，月生活费 2000 元。每年闲置物品价值约 500 元（教材、电子产品、生活用品）。曾用闲鱼卖旧教材，因跨城交易邮费 12 元占售价 30% 放弃。理想方案是同校面交、无需邮费、信用背书。可接受 9.9 元/月会员费。决策因素：信任度 > 价格 > 便利性。

### 7.4 用户调研规范

调研方法 3 类，至少选 2 类：
- 深度访谈：N≥10，每人 30~60 分钟，记录痛点/付费意愿
- 问卷调查：N≥100，含量化问题（价格区间、使用频次）
- 焦点小组：N=6~8 / 组，讨论产品形态与功能优先级

调研结论必须含：样本量 + 关键发现 + 量化数据（如"68% 用户接受 9.9 元/月"）。

### 7.5 CAC/LTV 测算

CAC（获客成本）= 推广预算 / 新增用户数
LTV（用户生命周期价值）= 客单价 × 复购次数 × 毛利率

健康指标：
- LTV/CAC ≥ 3（商业模式可持续）
- LTV/CAC < 1（商业模式不成立，需重新设计）
- 回收期 ≤ 12 个月（获客投入 1 年内回本）

测算示例：
- CAC：推广 5000 元 / 新增 1000 用户 = 5 元/人
- LTV：客单价 30 元 × 复购 4 次 × 毛利率 40% = 48 元
- LTV/CAC = 48/5 = 9.6（健康）
- 回收期：5/（30×40%/12）= 5 月

### 7.6 市场分析反例

❌ "市场前景广阔，需求旺盛，本项目具有巨大的市场潜力。"
问题：无数据、无来源、无测算。

✅ 见 4.4 节示例。三级市场测算含数据来源、竞品分析有矩阵、用户画像有量化调研。

每行必须有计算依据：
- 营收 = 用户数 × 客单价 × 复购次数
- 营业成本 = 服务器 + 履约 + 客服 + 支付通道费
- 毛利率 = 1 - 营业成本/营收
- 净利润 = 营收 - 营业成本 - 期间费用

### 8.2 盈亏平衡点

盈亏平衡点（BEP）= 固定成本 /（1 - 变动成本率）
或：月营收达 X 万元时毛利率覆盖固定成本。

示例：固定成本 3 万元/月，毛利率 40%，则 BEP 月营收 = 3/40% = 7.5 万元。预期 Year2 第 6 个月达到。

### 8.3 财务预测反例

❌ "Year1 营收 100 万，Year2 营收 500 万，Year3 营收 2000 万。"
问题：无算法、无用户数、无成本、无利润、无依据。

✅ 见 4.8 节示例。每项有算法、3 年完整、含盈亏平衡点说明。

### 8.4 财务预测合理性

- Year1 用户数 ≤ SOM × 5%（保守估计）
- Year3 用户数 ≤ SOM × 30%（激进但合理）
- 毛利率 30%~60%（互联网行业平均）
- 净利率 Year1 可为负，Year3 应转正
- 增长率 Year2/Year1 ≥ 3 倍，Year3/Year2 ≥ 2 倍（互联网增速）

### 8.5 启动资金需求

3 类资金来源：
- 大创经费：1~2 万（国家级）、5 千~1 万（省级）、2~3 千（校级）
- 自筹资金：团队成员自掏，建议 5 千~2 万
- 拟融资额：天使轮 50~200 万（写明用途：产品研发 / 用户获取 / 团队扩张）

## 九、评审标准与打分维度

### 9.1 五维评分（参考西南大学、合肥工业大学创业训练评审办法）

| 维度 | 权重 | 评分要点 | 高分标准 | 低分表现 |
|------|------|----------|----------|----------|
| 商业可行性 | 35% | 商业模式清晰、盈利模式可落地、CAC/LTV 合理 | 画布 9 要素齐全、有定价依据、LTV/CAC≥3 | 盈利模式模糊、"多元化盈利" |
| 市场分析 | 25% | TAM/SAM/SOM 测算、竞品矩阵、用户画像 | 三级测算有数据、竞品 5 列对比、画像量化 | "市场广阔"无数据 |
| 团队 | 20% | 商科+技术+设计复合、分工合理 | 表格列分工+专业+经历、体现互补 | 全是同专业、无分工 |
| 创新性 | 15% | 商业模式/产品形态差异化 | 有竞品对比、有差异化定位、有 MVP 验证 | "颠覆性""首次"无支撑 |
| 规范性 | 5% | 格式正确、栏目齐全、表述清晰 | 字数合规、表格规范、序号统一 | 错别字、格式乱 |

### 9.2 评审流程

- 国家级创业训练通过率约 25%（比创新训练低 5%）
- 评审专家 3 人/项目，至少 1 名有创业/投资背景
- 评审时长：每份约 10~15 分钟
- 部分省级评审增加路演答辩环节（5 分钟陈述 + 3 分钟答辩）

### 9.3 高分申报书特征

- 项目名称 ≤25 字，含产品代号（如"易舍"）
- 项目简介 4 句话讲完整，含市场+模式+目标+现状
- TAM/SAM/SOM 测算有数据来源
- 商业模式画布 9 要素齐全
- 竞品分析 5 列对比表
- 用户画像有量化调研（N≥50）
- 财务预测 3 年表格 + 盈亏平衡点
- 团队 4~5 人，商科+技术+设计复合
- 风险分析 4 类齐全
- 预期成果以商业计划书+模拟运营报告为主

### 9.4 低分申报书特征（任一即扣大分）

- 项目名称堆"基于...的..."
- 项目简介全是背景铺垫无商业模式
- 商业模式写"多元化盈利"无具体定价
- 市场分析无 TAM/SAM/SOM 测算
- 竞品只列名字无对比
- 财务预测只写营收无成本无利润
- 团队全是同专业无技术/设计
- 风险分析只写"风险可控"
- 预期成果写"若干"
- 预算全整数无依据
- 把学术研究内容（文献综述、技术路线流程图）混入

### 9.5 评分计算示例

假设 3 位评审专家打分：

| 维度 | 权重 | 专家 A | 专家 B | 专家 C | 平均 | 加权得分 |
|------|------|--------|--------|--------|------|----------|
| 商业可行性 | 35% | 85 | 80 | 88 | 84.3 | 29.5 |
| 市场分析 | 25% | 80 | 75 | 85 | 80.0 | 20.0 |
| 团队 | 20% | 85 | 85 | 80 | 83.3 | 16.7 |
| 创新性 | 15% | 80 | 75 | 85 | 80.0 | 12.0 |
| 规范性 | 5% | 90 | 85 | 90 | 88.3 | 4.4 |
| 合计 | 100% | - | - | - | - | 82.6 |

最终得分 82.6 分。国家级创业训练录取线通常 80+，省级 75+，校级 70+。

### 9.6 提分策略

- 商业可行性（35%权重最大）：优先打磨商业模式画布，确保 9 要素齐全、盈利模式有定价
- 市场分析（25%）：TAM/SAM/SOM 测算有数据、竞品矩阵完整、用户画像量化
- 团队（20%）：成员表列分工+专业+经历，体现商科+技术+设计复合
- 创新性（15%）：竞品对比突出差异化定位、附 MVP 验证数据
- 规范性（5%）：字数合规、表格规范、错别字 0 容忍

## 十、避坑指南与正反例对照

### 坑 1：项目名称堆"基于...的..."

❌ 基于微信小程序的面向高校校园闲置物品流转的智能匹配平台研究
✅ 校园闲置物品流转平台"易舍"

要点：≤25 字，含产品代号，不堆"基于""面向""智能"。

### 坑 2：简介全是背景铺垫无商业模式

❌ "随着共享经济发展，二手交易市场前景广阔。本项目基于微信小程序开发校园闲置物品交易平台，具有重要意义。"
✅ "本项目针对高校闲置物品流转效率低、传统跳蚤市场信息不对称的痛点，开发校园闲置物品流转平台'易舍'。通过 LBS 同校面交 + 信用积分，服务 18~24 岁在校生，预期 6 个月覆盖 5 校、月活 5000+。采用'交易抽佣 5% + 增值会员 9.9 元/月'盈利模式，预期 Year1 营收 12 万元。"

### 坑 3：商业模式写"多元化盈利"

❌ "本项目采用多元化盈利模式，通过创新的方式实现商业价值。"
✅ 见 6.4 节示例，明确抽佣 + 会员 + 广告 3 种模式 + 定价 + 占比。

### 坑 4：市场分析无 TAM/SAM/SOM

❌ "二手交易市场规模巨大，前景广阔，本项目具有巨大市场潜力。"
✅ 见 4.4 节示例，TAM 250 亿/SAM 6.4 亿/SOM 1272 万，含数据来源。

### 坑 5：竞品只列名字无对比

❌ "竞品有闲鱼、转转、校园跳蚤市场。"
✅ 见 4.4 节竞品分析表，5 列对比（名称/定位/用户规模/优势/劣势）。

### 坑 6：财务预测只写营收无成本

❌ "Year1 营收 100 万，Year2 营收 500 万，Year3 营收 2000 万。"
✅ 见 4.8 节财务表，含营收/成本/毛利率/净利润/净利率 5 行 + 盈亏平衡点说明。

### 坑 7：团队全是同专业无技术

❌ "团队成员：张三、李四、王五、赵六，均为工商管理专业。"
✅ 见 4.9 节团队表，工商管理 + 计算机 + 软件 + 市场营销 + 视觉传达 5 专业复合。

### 坑 8：风险分析只写"风险可控"

❌ "本项目风险可控，团队具有应对能力。"
✅ 见 4.10 节风险表，4 类风险 × 概率 + 影响 + 应对措施。

### 坑 9：预期成果写"若干"

❌ "预期形成商业计划书若干、用户调研报告若干。"
✅ 见 4.11 节预期成果，6 项含数量 + 形态 + 验收标准。

### 坑 10：预算全整数无依据

❌ "服务器 2000 元，调研 3000 元，推广 5000 元，合计 10000 元。"
✅ 见 4.12 节预算表，金额非整数 + 计算依据。

### 坑 11：商业模式画布少要素

❌ 画布只填 6 格（缺重要伙伴、关键业务、渠道通路），评审认为商业模式不完整。
✅ 9 要素必须齐全，每格 30~50 字，缺一不可。空格写"暂无"也比留空强。

### 坑 12：财务预测无盈亏平衡点

❌ 只给 3 年营收/成本表，不写何时盈利。
✅ 必须含盈亏平衡点测算："Year2 第 6 个月月营收达 7.5 万元时毛利率覆盖固定成本"。

### 坑 13：用户画像只写"年轻群体"

❌ "目标用户为 18~35 岁年轻群体，对互联网产品接受度高。"
✅ 见 7.3 节画像，6 要素齐全（基本信息+行为+痛点+需求+付费意愿+决策因素）。

### 坑 14：把学术研究内容混入创业训练

❌ 申报书含大量"文献综述""技术路线流程图""国内外研究现状"。
✅ 创业训练评审重点是商业可行性，不是学术创新。技术部分只写"产品技术实现"即可，文献综述 1~2 句带过。

### 坑 15：把创业实践特征写入创业训练

❌ "本项目已注册公司、实际营收 100 万、A 轮融资 500 万。"
✅ 创业训练不要求注册公司、不要求真实营收。如已注册，作为"加分项"简述；主体内容仍是商业计划与模拟运营。

### 坑 16：风险应对只写"加强管理"

❌ "针对市场风险，团队将加强管理、密切关注市场动态。"
✅ 见 4.10 节风险表，每类风险写具体应对动作（如"闲鱼进入校园则强化社团合作深耕单校"）。

## 十三、学校差异处理

不同学校创业训练模板有微调，处理规则：

**栏目顺序差异**：个别学校把"财务预测"放在"商业模式"前，或合并"团队介绍"与"前期基础"。按学校下发模板顺序调整 build.py 的 build() 方法调用顺序。

**字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。

**页边距差异**：部分学校要求 3cm 左右边距。修改 build.py setup_page() 中的 left_margin/right_margin。

**栏目增减**：
- 校级通常无"学校审批意见"栏 → 删除 _add_signature_section() 中的对应行
- 部分学校增加"中期检查计划"栏 → 在 build() 中追加 _add_midterm_check() 方法
- 部分学校要求"创业导师意见"栏（区别于指导教师）→ 增加独立签字栏

**级别差异**：
- 国家级：13 栏目全要 + 经费 1~2 万 + 商业模式画布 9 要素齐全 + 3 年财务预测
- 省级：13 栏目全要 + 经费 5 千~1 万 + 商业模式画布 9 要素齐全 + 2 年财务预测
- 校级：可省"学校审批意见"栏 + 经费 2~3 千 + 商业模式画布可省 1~2 要素 + 1 年财务预测

适配流程：先问"学校下发的模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按国家级模板处理。适配完成后告知用户"已按 XX 学校模板调整，请核对栏目顺序与字体"。

适配修改记录到 worklog.md，便于后续项目复用。

### 13.3 模板适配后自检

适配完成后逐项自检：
- 栏目顺序与学校模板一致
- 字体符合学校要求（宋体/仿宋/楷体）
- 页边距符合学校要求
- 增减栏目已落实到 build.py
- 生成 docx 后人工目测与学校模板对齐

自检不通过 → 重新调整 build.py → 再生成 → 再自检。适配修改与学校差异均记录到 worklog.md，便于后续项目复用与版本追溯。
